# 천하장사

아주대학교 AI 캡스톤디자인 **12조 천하장사**의 공급업체 탐색 서비스입니다.

## MVP 사용자 가이드

### 서비스 소개

식자재 구매를 담당하는 소규모 식당 사장님이 새 판매처를 찾거나 받은 견적이 적절한지 판단할 때, 여러 가게에 하나씩 물어봐야 하는 부담을 줄이는 서비스입니다. 이번 MVP에서는 주변 업체를 지도에서 살펴보고, AI 도우미에 상추 구매 조건을 입력해 예시 판매처를 찾거나 kg당 단가를 비교할 수 있습니다.

### 접속 방법

**[천하장사 웹 MVP 열기](https://cheonhajangsa-mvp.vercel.app/)**

- 휴대폰이나 PC 브라우저에서 접속합니다. Chrome을 권장합니다.
- 아래 지도·AI 체험은 설치, 로그인, 테스트 계정, 별도 파일 없이 진행합니다. 저장과 대화 등 로그인 안내가 나오는 기능은 이 체험 범위에서 제외합니다.
- 시연 데이터는 앱에 들어 있습니다. 저장소에서 확인하려면 [MVP 샘플 데이터](apps/cheonhajangsa-mvp/data)를 참고하세요.

### 핵심 기능 체험 순서

**상황**　오늘 상추 2kg이 급히 필요한 식당 사장님입니다. 직접 가지러 갈 후보를 찾고, 받은 견적 10,000원이 kg당 얼마인지 확인해 보세요.

| 단계 | 이렇게 해 보세요 | 이렇게 나오면 정상입니다 |
|---|---|---|
| 1. 지도에서 업체 보기 | 첫 화면의 **지도**에서 업체 핀 하나를 누릅니다. 핀을 고르기 어려우면 하단 **목록 보기**를 누릅니다. | 핀을 누르면 하단 **선택하신 업체**에 업체 카드가 표시됩니다. 목록을 열면 주변 업체를 볼 수 있습니다. |
| 2. 상추 판매처 찾기 | 하단 **AI 도우미**를 열고 `상추 2kg`을 보냅니다. 화면에 나오는 질문에 답합니다. 필요 시점은 **지금 바로**, 수령 방법은 **직접 갈게요**를 선택합니다. | 조건과 예시 판매처 카드가 나옵니다. **검색 결과 지도에서 보기**를 누르면 지도 탭으로 이동합니다. 표시되는 영업 상태는 접속 시간에 따라 달라질 수 있습니다. |
| 3. 받은 견적 비교하기 | **AI 도우미** 오른쪽 위의 연필 아이콘(**새 대화**)을 누르고 `상추 2키로 만원 부르던데`를 보냅니다. | 단가 진단에 **상추 kg당 5,000원**이 표시됩니다. 비교 자료가 있으면 동네 시세와의 차이도 함께 확인할 수 있습니다. |

**다른 조건으로 다시 실행하기**　검색 결과 위에서 수량이나 수령 방법을 눌러 바꾸면 새 조건으로 검색됩니다. 처음부터 하려면 **새 대화**를 누르고 `상추 5키로 오늘 배달`을 입력해 보세요.

### 제한과 문제 해결

- 품목 조건 검색과 단가 진단은 **상추**를 중심으로 체험합니다. 예시 판매처의 가격과 전화번호는 가상이며, 공공데이터 지도 업체의 실제 가격·재고는 보장하지 않습니다. 예시 판매처의 **전화하기**는 안내만 표시합니다. 앱에서 주문과 결제는 할 수 없습니다.
- AI가 응답하지 않으면 **조건을 직접 골라 주세요** 화면에서 검색을 이어갑니다. **저장 응답**이 표시되면 위 표의 예시 문장을 그대로 입력하세요. 사진 진단이 어려우면 가격을 텍스트로 입력하면 됩니다.
- 지도가 뜨지 않으면 새로고침하거나 Chrome에서 다시 열어 보세요. 목록이 열리면 **목록 보기**로 업체를 확인할 수 있습니다.
- 팀 리허설에는 [테스트 링크](https://cheonhajangsa-mvp.vercel.app/?test=1)를 사용합니다. 같은 브라우저에서 일반 체험으로 돌아갈 때는 [테스트 모드 해제](https://cheonhajangsa-mvp.vercel.app/?test=0)를 엽니다.

## 현재 MVP 코드

시연 앱은 `apps/cheonhajangsa-mvp/`의 Expo 웹 앱이며 Vercel에서 배포합니다. 사용법, 로컬 실행, 환경 변수, 데이터와 기록 범위는 [MVP 앱 안내](apps/cheonhajangsa-mvp/README.md)에 정리돼 있습니다.

## 문제 근거 상태

- 자영업자 인터뷰 12건을 수행했습니다.
- `I01~I06`, `I09`, `I10`, `I12`의 9건은 구조화된 요약이 있습니다.
- `I07`, `I08`, `I11`은 음성은 있으나 구조화·직접 인용 대조가 남아 있습니다.
- 가격만이 아니라 품질·배송·운반·기존 관계가 선택 기준으로 관찰됐습니다.
- 공개 커뮤니티 공유와 지도 사용 필요성은 인터뷰만으로 확인되지 않았습니다.

따라서 지도형 업체 탐색은 검증 완료 요구사항이 아니라 **데이터 확보 가능성과 사용 행동을 시험하는 제품 실험**으로 다룹니다.

## 로컬 실행

Node.js 24로 `apps/cheonhajangsa-mvp/`에서 `npm ci`를 실행합니다. 환경 변수를 준비한 뒤 터미널을 두 개 열어 같은 폴더에서 각각 `npm run dev:api`와 `npm run web`을 실행하고, 브라우저에서 `http://localhost:8081`을 엽니다. 환경 변수와 검사 명령은 [개발자용 실행 안내](apps/cheonhajangsa-mvp/README.md#2-직접-실행하기-개발자용)를 참고합니다.

## 데이터 구분

- `live`: 업체가 제출하고 운영자가 승인한 공개본
- `mvp_demo`: 공공 업체 원문과 명시적으로 분리된 가상 시연 가격·조건
- `[가상테스트]`: 자동 테스트와 화면 검증용 fixture

가상 가격을 실제 업체 가격, 견적 또는 검증된 거래 정보로 표현하지 않습니다. [공공업체 MVP 출처와 제한](docs/data-sources/public-vendor-mvp.md)을 확인합니다.

## 브랜치와 승인

- `main`에 직접 작업하지 않습니다.
- 개인 브랜치에서 커밋하고 PR로 변경 이유·검증 명령·미검증 항목을 공유합니다.
- DB schema, API 계약, 인증·공개 범위, 제품 P0 변경은 팀원 승인 후 병합합니다.
- 평가 보완 변경은 개인 브랜치의 PR에서 검토합니다.
