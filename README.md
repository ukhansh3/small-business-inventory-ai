# 천하장사

주변 식자재 판매처를 찾고, 받은 견적을 kg당 가격으로 비교하는 서비스입니다. 식자재를 직접 구매하는 소규모 식당 사장님을 위해 만들었습니다.

아주대학교 AI 캡스톤디자인 12조 · 팀 천하장사

## MVP 사용자 가이드

**[천하장사 열기](https://cheonhajangsa-mvp.vercel.app/)**

휴대폰이나 PC 브라우저에서 열면 됩니다. 지도와 AI 도우미는 설치나 가입 없이 써볼 수 있습니다. 저장과 대화는 로그인이 필요합니다.

### 상추 2kg 사러 갈 곳 찾기

오늘 상추 2kg이 필요한 식당 사장님이라고 생각하고 따라 해 보세요.

1. **지도에서 업체 보기**  
   지도에서 핀을 누르면 아래에 업체 카드가 나옵니다. 핀을 누르기 어렵다면 **목록 보기**를 누르세요.
2. **AI 도우미에게 물어보기**  
   아래 탭에서 **AI 도우미**를 열고 `상추 2키로 급해요`를 보냅니다. 화면에 나오는 질문에 답하고, 수령 방법은 **직접 갈게요**를 고릅니다. 결과에서 업체 카드를 확인하거나 **검색 결과 지도에서 보기**를 누르세요.
3. **받은 견적 비교하기**  
   AI 도우미 오른쪽 위 연필 아이콘(**새 대화**)을 누르고 `상추 2키로 만원 부르던데`를 보냅니다. **kg당 5,000원**이 나오고, 비교 자료가 있으면 동네 시세와의 차이도 표시됩니다.

수량이나 수령 방법만 바꾸려면 검색 결과 위의 조건을 누르세요. 처음부터 해보려면 **새 대화**에서 `상추 5키로 오늘 배달`을 보내면 됩니다.

### 체험 전 알아두기

- 이번 시연의 조건 검색과 단가 진단은 상추를 기준으로 합니다. 예시 판매처의 가격과 전화번호는 가상이며, 공공데이터 업체의 가격·재고는 미확인입니다. 주문과 결제는 제공하지 않습니다.
- AI가 답하지 못하면 **조건을 직접 골라 주세요** 화면에서 이어가세요. **저장 응답**이 표시되면 위 예시를 그대로 입력하세요. 지도가 안 뜨면 새로고침하거나 **목록 보기**를 이용하세요.
- 샘플은 앱에 포함되어 있습니다. [샘플 데이터](apps/cheonhajangsa-mvp/data) · [리허설 모드](https://cheonhajangsa-mvp.vercel.app/?test=1) · [일반 모드로 돌아가기](https://cheonhajangsa-mvp.vercel.app/?test=0)

**리뷰 기간은 2026년 11월 11~18일입니다.** 접속 주소나 체험 방법이 바뀌면 이 안내를 갱신합니다.

## 문제 근거 상태

- 자영업자 인터뷰 12건을 수행했습니다.
- 12건의 구조화 요약이 있습니다. `I07`, `I08`, `I11`은 자동 전사 기반으로 정리했고 직접 인용·수치의 원음 대조는 남아 있습니다.
- 가격만이 아니라 품질·배송·운반·기존 관계가 선택 기준으로 관찰됐습니다.
- 공개 커뮤니티 공유와 지도 사용 필요성은 인터뷰만으로 확인되지 않았습니다.

따라서 지도형 업체 탐색은 검증 완료 요구사항이 아니라 **데이터 확보 가능성과 사용 행동을 시험하는 제품 실험**으로 다룹니다.

## 로컬 실행

Node.js 24를 사용합니다. `apps/cheonhajangsa-mvp/`에서 `npm ci`를 실행하고 [환경 변수](apps/cheonhajangsa-mvp/README.md#2-직접-실행하기-개발자용)를 준비하세요. 터미널 두 개에서 각각 `npm run dev:api`, `npm run web`을 실행한 뒤 `http://localhost:8081`을 엽니다.

## 데이터 구분

- `live`: 업체가 제출하고 운영자가 승인한 공개본
- `mvp_demo`: 공공 업체 원문과 명시적으로 분리된 가상 시연 가격·조건
- `[가상테스트]`: 자동 테스트와 화면 검증용 fixture

가상 가격을 실제 업체 가격, 견적 또는 검증된 거래 정보로 표현하지 않습니다. [공공업체 MVP 출처와 제한](docs/data-sources/public-vendor-mvp.md)을 확인합니다.

## 브랜치와 승인

- `main`에 직접 작업하지 않습니다.
- 개인 브랜치에서 커밋하고 PR로 변경 이유·검증 명령·미검증 항목을 공유합니다.
- DB schema, API 계약, 인증·공개 범위, 제품 P0 변경은 팀원 승인 후 병합합니다.
- 평가 보완 변경은 개인 브랜치의 PR에서 검토합니다.
