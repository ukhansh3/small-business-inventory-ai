# 지역 자영업자 정보 비대칭 문제 탐색 프로젝트

아주대학교 AI 캡스톤디자인 팀 프로젝트입니다. 현재는 완성된 서비스 아이디어를 구현하는 단계가 아니라, 실제 자영업자 인터뷰를 바탕으로 해결할 문제와 최소 기능을 검증하는 단계입니다.

- 202020794 차승호

## 현재 문제 정의

개업 초기 자영업자는 거래처, 식자재 시세, 설비 수리, 폐기물·폐유 처리, 점포 집기 등의 적정 가격과 신뢰할 수 있는 업체 정보를 판단하기 어렵습니다. 필요한 정보가 공개된 데이터보다 지인과 주변 점주의 경험에 머물러 있어, 인맥과 업력에 따라 탐색 시간과 거래 조건이 달라질 수 있다는 가설을 검증하고 있습니다.

현재 검토 중인 해결책은 자영업자 간 중고 집기 거래, 도·소매 가격 정보, 업체·거래처 후기, 지도 기반 주변 정보 등을 묶은 지역 플랫폼입니다. 아직 핵심 기능은 확정하지 않았습니다.

## 여기까지 온 과정

1. 대학생 팀플, 취업 준비, 자취생 식비 등 접근 가능한 도메인에서 출발했습니다.
2. 세 차례 브레인스토밍을 거쳐 악기 연습 피드백, 무인매장 배회 알림, 식자재 발주량 예측, 반려견 오디오 리포트 등을 후보로 검토했습니다.
3. 실제 사용자를 빠르게 만날 수 있는 자영업 도메인으로 범위를 좁혔습니다.
4. 재고·품절·피크타임·개폐업 정보 문제를 가설로 세웠고, 이후 생산자 직거래와 식당 간 공동구매 아이디어를 검토했습니다.
5. 아주대 상권 외식업 6곳을 인터뷰한 결과, 대부분 필요한 식자재를 매일 또는 2~3일마다 소량 구매했고 가격보다 신선도, 빠른 배송, 기존 거래 관계를 중시했습니다.
6. 공동구매의 전제는 약하다고 판단했습니다. 대신 학사일정에 따른 수요 변동과 점주 간 정보 비대칭이 예상하지 못한 신호로 반복되었습니다.
7. 초기 인터뷰 6건을 검토한 뒤 초보 사장님의 거래처·가격 정보 비대칭을 더 확인하도록 질문을 수정했고, 같은 문제 탐색의 연장선에서 총 11명을 인터뷰했습니다.

자세한 흐름은 [프로젝트 탐색 연대기](docs/history/README.md)에서 확인할 수 있습니다.

## 현재 상태

- 문제 영역: 초보 자영업자의 가격·거래처 정보 비대칭
- 검증 대상: 아주대 상권, 개업 3년 이내, 거래처나 외부업체를 직접 정한 점주
- 검증 중인 항목: 문제 발생 빈도, 탐색 시간·비용, 가격 판단 기준, 다른 점주와의 정보 교환
- 아직 미정인 항목: 첫 번째 핵심 기능, 지도 사용 여부, 중고거래 포함 여부, 가격 정보의 수집 방식, 수익 모델
- 보류한 방향: 식당 간 공동구매, 자동 발주량 예측, 크로스 플랫폼 품절 동기화

## 문서 구조

```text
docs/
  history/       문제 탐색과 피벗의 시간순 기록
  decisions/     중요한 선택과 근거를 남긴 의사결정 기록
  interviews/    인터뷰 대본, 기록 양식, 익명화된 결과
  product/       현재 문제 정의와 해결책 후보
```

음성 녹음, 연락처, 점주 실명과 같은 개인정보는 공개 저장소에 올리지 않습니다. 원본은 `private/` 또는 저장소 밖에서 관리하고, Git에는 익명화된 관찰 사실과 인용만 남깁니다.

## 다음 분석

완료한 인터뷰 11건을 동일한 기준으로 코딩한 뒤 정보 비대칭 가설을 판단합니다. 질문이 중간에 바뀌었으므로 묻지 않은 항목은 반대 증거가 아니라 `확인하지 못함`으로 처리합니다.

- 거래처 또는 업체를 새로 판단한 구체적 사건이 몇 건인지 확인합니다.
- 복수 업체 접촉, 탐색 시간 또는 금전 손해가 반복됐는지 확인합니다.
- 점주 간 가격·거래처 정보 교환이 실제 행동으로 나타났는지 확인합니다.
- 가장 반복적이고 비용이 큰 문제 하나를 첫 MVP 범위로 선택합니다.
