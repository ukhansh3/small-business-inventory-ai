### 코드는 구현했지만 전체 실사용 검증이 남은 것

- 회원가입·이메일 확인·로그아웃·세션 유지의 전체 흐름
- 업체 초안 등록·수정, 여러 품목과 가격·거래 조건 저장
- 업체 사진 선택·비공개 업로드·권한에 따른 조회
- 카카오 주소 좌표 확인 후 검토 요청
- 사장 앱에서 제출 → 운영자 앱에서 보완·승인 → 지도 공개까지 전체 과정
- 승인된 정보는 유지하면서 수정본 재검토 (DB 함수 실행은 확인)
- 실제 기기 현재 위치·권한 처리
- 업체 숨김·재공개는 서버·DB만 구현, 모바일 버튼은 미구현

### 서버 운영·출시에서 남은 것

- API·지도 페이지는 `https://cheonhajangsa.vercel.app`에 배포되어 있고 DB는 Supabase를 사용합니다.
- Expo Go 개발 실행에는 앱 코드를 전달하는 개발 컴퓨터가 필요합니다. 독립 설치 앱의 제작·배포 검증은 남아 있습니다.
- 정식 운영자 지정과 실제 등록·승인 흐름 검증이 남아 있습니다.
- 현재 DB 연결 버전의 정식 APK·iOS 배포 검증, 스토어 출시는 미완료입니다.
- 키·`.env.local`은 Git에 포함되지 않습니다.

상세 근거와 다음 작업 순서는 [구현·미구현 기능 현황](docs/product/implementation-status.md)을 확인합니다. 실연결 검증은 2026-10-29 기록 기준이며, 현재 서버가 켜져 있다는 의미는 아닙니다.

## 현재 문제 정의

자영업자가 익숙하지 않은 품목이나 거래처를 새로 알아볼 때, 적정 가격과 업체 품질을 판단할 공개된 기준이 부족할 수 있습니다. 현재 인터뷰에서는 업력 자체보다 기존 경험, 저장해 둔 연락처, 업계 지인의 유무가 탐색 방식에 영향을 주는 모습이 확인됐습니다. 다만 이것이 반복적이고 비용이 큰 문제인지는 아직 결론 내리지 않았습니다.

도·소매 가격 기준, 거래처 탐색, 외부업체 정보 등을 후보로 검토하고 있지만 첫 기능은 확정하지 않았습니다. 중고 집기 거래, 지도, 점주 간 공개 공유는 현재 인터뷰만으로 필요성이 확인되지 않은 아이디어입니다.

## 현재 제품 가설: 천하장사

발표와 프로토타입에서는 지도 기반 가격·조건 비교를 핵심 흐름으로 잡고, AI 음성 도우미, 사장님 커뮤니티·DM, 잔여재료·중고 설비 거래를 보조 흐름으로 설계했습니다. 제품명은 `천하장사`이며 지도 핀과 가격표를 결합한 주황색 심볼을 사용합니다.

이 구성은 검증이 끝난 요구사항이 아니라 다음 사용자 테스트를 위한 제품 가설입니다. 첫 MVP는 한 지역과 1~2개 카테고리의 가격·배송·최소 주문량·확인일 비교에 우선순위를 둡니다.

## 여기까지 온 과정

1. 대학생 팀플, 취업 준비, 자취생 식비 등 접근 가능한 도메인에서 출발했습니다.
2. 세 차례 브레인스토밍을 거쳐 악기 연습 피드백, 무인매장 배회 알림, 식자재 발주량 예측, 반려견 오디오 리포트 등을 후보로 검토했습니다.
3. 실제 사용자를 빠르게 만날 수 있는 자영업 도메인으로 범위를 좁혔습니다.
4. 재고·품절·피크타임·개폐업 정보 문제를 가설로 세웠고, 이후 생산자 직거래와 식당 간 공동구매 아이디어를 검토했습니다.
5. 첫날 5곳, 둘째 날 2곳까지 모두 7곳을 기존 질문으로 인터뷰했습니다. 이 가운데 먼저 정리된 6건에서는 필요한 식자재를 매일 또는 2~3일마다 소량 구매하고, 가격뿐 아니라 신선도·빠른 배송·기존 관계를 중시하는 행동이 확인됐습니다.
6. 공동구매의 전제는 약하다고 판단했습니다. 대신 학사일정에 따른 수요 변동과 거래처·외부업체 정보의 비대칭이 예상하지 못한 신호로 나타났습니다.
7. 7번째 인터뷰까지 마친 뒤 정보 비대칭을 더 구체적으로 확인하도록 질문을 수정했고, 같은 문제 탐색의 연장선에서 5곳을 더 방문해 총 12명을 인터뷰했습니다.

자세한 흐름은 [프로젝트 탐색 연대기](docs/history/README.md)에서 확인할 수 있습니다.

## 현재 상태

- 문제 영역: 익숙하지 않은 품목·거래처·외부업체를 판단할 때의 정보 부족
- 실제 표본: 아주대 인근 외식업 점주 12명. 수정 대본은 개업 3년 이내를 우선했지만 실제로는 장기 운영 점주도 포함됨
- 분석 중인 항목: 문제 발생 빈도, 탐색 시간·비용, 가격 판단 기준, 기존 경험·인맥의 영향, 정보 교환 의사
- 아직 미정인 항목: 첫 번째 핵심 기능, 지도 사용 여부, 중고거래 포함 여부, 가격 정보의 수집 방식, 수익 모델
- 보류한 방향: 식당 간 공동구매, 자동 발주량 예측, 크로스 플랫폼 품절 동기화

## 분석 기준

인터뷰 12건 가운데 구조화된 정리 내용이 있는 9건을 현재 가설 판정의 근거로 사용했습니다. `I07`, `I08`, `I11`은 인터뷰 수행과 음성 자료만 반영했으며 개별 발언이나 수치 집계에는 사용하지 않았습니다. 질문이 중간에 바뀌었으므로 묻지 않은 항목은 반대 증거가 아니라 `확인하지 못함`으로 처리했습니다.

- 거래처 또는 업체를 새로 판단한 구체적 사건을 기준으로 분류했습니다.
- 복수 업체 접촉, 탐색 시간과 금전 손해가 실제로 언급됐는지 구분했습니다.
- 점주 간 가격·거래처 정보 교환은 의향이 아니라 과거 행동을 근거로 판단했습니다.
- 구체적인 근거가 없는 지도·중고거래 기능은 현재 범위에 포함하지 않았습니다.
