# 현행 MVP DB 준비

이 경로는 `apps/cheonhajangsa-mvp/`의 DB다. 루트 `supabase/`는 이전 업체 등록 앱의 기록이므로 현재 앱 실행을 위해 임의로 적용하지 않는다.

| migration | 용도 |
|---|---|
| 0001~0005 | 익명 기기·대화·요청·한도·가격 진단·시세에서 테스트 기기 제외 |
| 202611080001 | 커뮤니티 글·댓글·반응·신고와 업체 저장 |
| 202611090001~202611090005 | 가상 시연 업체·이용 기록·집계 |
| 202611090006 | 업체 리뷰 |
| 202611090007~202611090008 | 업체 소유자·문의 대화·읽음 상태 |

기존 팀 프로젝트에 같은 SQL을 다시 실행하지 않는다. 신규 프로젝트는 각 파일의 의존성·예시 데이터·정책을 검토한 뒤 담당자가 적용한다. migration 파일이 있다는 사실만으로 원격 적용이 끝났다고 기록하지 않는다. 이 평가 보완 작업은 원격 SQL을 실행하지 않는다.

서버에 `SUPABASE_URL`, `SUPABASE_SERVICE_ROLE_KEY`를 설정한다. 클라이언트 번들에 서비스 키를 넣지 않는다. 회원 API는 Bearer 토큰을 검증하고 사용자 ID를 서버에서 결정한다. Auth의 사이트·허용 리디렉션 URL과 실제 배포 주소를 맞춘다.

리뷰·문의에는 해당 테이블이 필요하다. 업체 문의는 소유자 계정 연결이 필요하며 임의의 실제 사용자를 업체 소유자로 지정하지 않는다. 회원 테이블·메일 인증·복수 계정 테스트 결과는 [검증 기록](../../../docs/evaluation/midterm-2-readiness.md)에 별도로 남긴다. DB가 없으면 503을 오류로 표시해야 하며 샘플 성공으로 바꾸지 않는다.
