# 수용 기준

> 우선순위 2위. AC 번호는 기획서 9절·API 명세 6절과 같다(AC-3은 과거 빈 번호, 회원 기능은 AC-M01~AC-M06). 테스트 이름에 AC 번호를 붙인다.
> 판정 데이터는 `data/` 고정 데이터와 테스트용 시각(`X-Debug-Now`, 테스트에서는 함수 인자 `now`)을 쓴다.

## 시나리오 1 — 상추 검색 (P0)
사장님이 '상추'를 입력 → 필요한 시점·받는 방식을 고름(수량 누락 허용) → 결과 목록 → 전화하기.

| AC | 조건 | 정상 결과 | 완료 판정 |
|---|---|---|---|
| AC-5 | '상추' 입력 | 수량 누락 시 qty_kg=null로 유지하고 첫 질문 urgency → fulfillment. '상추 2키로 급해요'면 첫 질문 fulfillment | API 테스트(저장된 응답) |
| AC-1 | 원하는 양 1kg, 판매처 A 최소 2kg | A 없음. 2kg이면 A 있음 | 단위 테스트 |
| AC-2 | 배달, 내 위치 원천동, 판매처 B 배달 동네 [우만동] | 영업 조건 충족 시 B는 `no_delivery`, '이 지역은 배송 범위 밖'. 상세 배송 필드는 루트 AC04 골든으로 확인 | 단위 테스트 |
| AC-4 | C 가격·단위(1박스 4kg)·출처·확인일 모두 / D 확인일 없음 | C '1박스(4kg) 15,000원 · 가게 안내 · 11월 3일 확인', '(kg당 약 3,800원)' / D '가격 정보 없음' | 단위 테스트(문자열 일치) |

## 시나리오 7 — 회원·커뮤니티·저장 (MVP)

닉네임, 구매처 질문·가격 제보·거래 경험, 삭제 상태 전이, 신고 수동 검토는 승인된 정책이다. 실제 Auth/DB 설정이 필요하며 가짜 DB를 사용한 API 테스트와 원격 실연결을 구분한다.

| AC | 조건 | 기대 결과 | 확인 |
|---|---|---|---|
| AC-M01 | 보호 경로에 토큰 없음·변조 토큰 / 유효한 로그인 / 프로필 수정 | 미인증 401·회원 DB 조회 없음. 사용자 ID는 검증 토큰에서 결정. 가입/재발송은 배포 주소로 안내, 닉네임 1~30자 | members.test.ts, 실제 인증 메일은 별도 |
| AC-M02 | 유효한 3분류 글 작성 / 잘못된 분류·100자 초과 제목 / 타인 글 수정·삭제 | 작성 201·토큰 작성자와 닉네임 저장. 잘못된 입력 422, 타인 수정 403·update 없음. 본인 삭제는 deleted 상태 전이, 물리 삭제 없음 | 회원 API 테스트, 글쓰기 E2E |
| AC-M03 | 댓글 1~1000자 / 타인 댓글 삭제 / 신고 1~1000자 | 댓글 작성 201. 타인 삭제 403. 신고는 중복 키로 접수하며 글 자동 숨김·삭제 없음 | 회원 API 테스트 |
| AC-M04 | 게시글 좋아요·북마크 PUT 반복 / DELETE / 저장 글 조회 | user_id·post_id·kind 키로 멱등 저장·해제. saved=true는 본인의 bookmark만 조회 | 회원 API·저장 화면 테스트 |
| AC-M05 | 업체 저장·해제 / 조회 불가 업체 | 토큰 사용자와 vendor_id로 한정. 저장 목록의 원천 정보가 없으면 store=null·확인 불가 표시. 가짜 업체 정보 생성 없음 | 회원 API·저장 화면 테스트 |
| AC-M06 | 미연결 업체 문의 / 다른 대화 참가자 접근 / 리뷰 별점 0·6 | 미연결 또는 권한 밖 대화 404. 참가자는 서버에서 제한. 별점은 1~5만 허용, 범위 밖 422 | 회원 API 테스트. 리뷰 DB·복수 계정 실연결은 별도 |

## 오류·예외 공통
| 상황 | 기대 |
|---|---|
| 빈 문장·201자 이상 | 400 `INVALID_INPUT`, 입력창 안내 |
| 세션 조건 | 현재는 stateless 조건 왕복. session_id=null이면 서버가 ID 생성, 잘못된 UUID는 400 |
| 비활성 품목으로 `/search` | 400 `ITEM_NOT_ACTIVE` |
| 기록(Supabase) 실패 | 사용자 응답은 정상 |
| 네트워크 끊김 | '연결이 끊겼어요' + 다시 시도 |
| 운영 배포에서 `X-Debug-Now` | 무시 |
| 사진이 너무 큼(디코딩한 이미지가 3MiB 초과)·이미지 아님 | 400 `INVALID_INPUT`, "사진을 다시 골라 주세요" |
| 사진 읽기 실패(AI) | 503 `AI_UNAVAILABLE`, "가격을 글로 적어 주세요" 안내 |
