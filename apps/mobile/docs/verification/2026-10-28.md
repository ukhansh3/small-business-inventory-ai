# 모바일 전환 검증

- 사용자 요청: 웹사이트 중심 코드를 Android·iPhone 공통 모바일 앱으로 전환. DB 변경 전 UI·구조 정비.
- 도구: Codex, Expo CLI, pnpm, TypeScript, ESLint, Vitest, Metro, Expo Go, Android adb, iOS simctl. 에이전트 생성 코드이며 사람의 코드 리뷰는 아직 받지 않았다.
- 구현: 네이티브 화면·탭·상세·업체 등록 폼, 공용 주황색 토큰, 위치 권한, 제한된 지도 WebView, 모바일 빌드·환경·개발 안내. DB migration/테이블/정책 변경 없음.
- 모바일: lint / typecheck 통과, Vitest 21개 통과, Android·iOS export 성공, Expo 의존성 검사 통과, peer 충돌 없음, expo-doctor 20/20 통과.
- 지원 웹 프로젝트: lint / typecheck / Vitest 17개 / production build 통과. /mobile-map 생성 확인.
- 실행: iPhone 15 Pro Max iOS 17.2 시뮬레이터의 Expo Go에서 홈 화면 표시. Android API 35 에뮬레이터의 Expo Go에서 홈 표시 및 내 업체 탭 이동 확인. 스크린샷은 같은 폴더에 보관.
- 설치 파일: 새 독립 APK/IPA 네이티브 컴파일 및 스토어 서명·업로드는 수행하지 않음. 기존 APK는 이번 앱과 다름.
- 지도: 초기에는 URL 미설정 상태의 설정 대기 화면과 목록 fallback을 확인. 이후 사용자가 전달한 https://cheonhajangsa.vercel.app 주소를 로컬 설정에 반영했으며 기존 배포의 /mobile-map은 404 응답을 확인. Kakao 실지도·타일·마커 실연결 검증은 배포 URL 설정 후 필요. 실제 키는 모바일 소스에 복사하지 않음.
- 한계: 모든 기종/OS, 태블릿, 접근성 확대, 실제 위치 허용·거부, 네트워크 장애, 전체 화면 E2E를 검증하지 않음. 로그인·서버 제출·승인·DB·실제 AI는 미연결. 현재 데이터는 가상 자료.
- 로컬 도구: Xcode 16.0, Android SDK 34 설치 상태여서 SDK 58 공식 권장 빌드 도구보다 낮다. 독립 네이티브 빌드는 도구 업데이트 또는 별도 EAS 빌드가 필요하다.
- 참고: https://docs.expo.dev/versions/v58.0.0/ , https://docs.expo.dev/router/installation/ , https://docs.expo.dev/versions/v58.0.0/sdk/webview/

- Android: 내 업체 → 업체 등록 폼 진입과 업체명·필수 가격 필드 표시를 추가 확인.
