# 데이터 비교 가능성 스파이크 v1 — 사전 등록안

- 상태: 팀 검토안 / 실행 전
- 작성일: 2026-11-04
- 관련 SPEC: 11절

## 가장 위험한 가정

팀은 한정된 품목군에서 규격·가격·배송·확인일·공개 가능한 출처를 갖춘 Offer를 반복적으로 확보하고 갱신할 수 있다.

이 가정이 실패하면 지도·AI·커뮤니티 UI가 있어도 실제 비교 서비스가 성립하지 않으므로 UI 사용성보다 먼저 검증합니다.

## 실험 단위

- 지역: 팀 승인 후 한 지역으로 고정
- 품목군: 팀 승인 후 한 품목군으로 고정
- 비교 규격: 같은 품명·규격·수량 단위·세금 기준
- 표본 단위: `Vendor × Offer` 1건
- 목표 표본: 10건

지역·품목군은 결과를 본 뒤 바꾸지 않습니다. 변경하면 v2 사전 등록을 새로 작성합니다.

## 필수 필드

- 공급업체 식별 정보
- 품목 또는 서비스명
- 규격
- 포장 수량과 단위
- 가격과 세금 상태
- 최소 주문
- 배송 지원과 조건
- 확인일
- 공개 가능한 출처 또는 업체 확인 기록

## 실패 처리

다음 중 하나면 비교 불가 1건으로 기록합니다.

- 필수 필드 누락
- 단위·규격·세금 기준 불일치
- 공개하거나 재확인할 출처 없음
- 확인일이 없거나 30일 초과
- 가상 시연 값을 실제 가격으로 사용

## 합격선 제안

- 10건 중 8건 이상이 동일 기준으로 비교 가능
- 한 건당 확인·입력 시간 중앙값 10분 이하
- 제3의 팀원이 출처에서 핵심 필드를 재확인 가능
- 실제·가상·미확인 값을 잘못 분류한 건수 0건

위 숫자는 팀 승인 전 제안값입니다. 승인 후 실행하고 결과를 본 뒤 수정하지 않습니다.
