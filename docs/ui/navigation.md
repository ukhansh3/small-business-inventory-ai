# 화면 내비게이션·라우팅 계획 (미구현 변경 예정)

```text
앱 시작 (로그인 페이지 없음)
└─ 탭 컨테이너
   ├─ 지도 / → 검색 → 업체 핀 → 하단 카드 → /vendor/[id]
   ├─ AI 도우미 → 채팅 → 추천 카드 '지도에서 보기' → 지도 선택 카드
   ├─ 커뮤니티 → 피드 → 상세/댓글, 글쓰기, (시연 moderator) 검토
   ├─ 저장 → 전체/업체/게시글 → 각 상세
   └─ 내 정보 → UI-only 업체 리스트/등록 상태 미리보기(준비 중)
```

- UI route labels: 지도, AI 도우미, 커뮤니티, 저장, 내 정보(변경 대상). Expo Router 실제 경로는 구현 직전 재검증.
- `AI → 지도에서 보기`는 현재 지도 탐색 화면으로 돌아가고 정확히 해당 vendor를 선택한 상태로 연다. 자동 지역 검색은 하지 않는다. 현재 `appliedBounds` 밖 업체를 볼 때 상태 충돌은 구현 결정 필요.
- 커뮤니티 글 상세/작성 화면은 독립 route. 저장 상태는 화면 전환 후 일관성 유지.
- 시연 초기화 동작 UI 위치는 제품 승인 전 임의 배치하지 않는다(사용자에게 로그인 요구 금지).
