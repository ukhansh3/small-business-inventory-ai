# UI-COMMUNITY-COMPOSE-001 — 게시글 작성 및 수정

**확정:** C-03, C-07, C-08, C-10.

## 입력 필드
- 화면 제목: 신규 `글쓰기`, 수정 `게시글 수정`.
- 카테고리 필수: `구매처 질문`, `가격 제보`, `거래 경험` 중 하나. `전체`는 작성 선택지에 없음.
- 제목(필수), 본문(필수), 사진 첨부(선택). 사진 미리보기/제거/업로드 진행 상태 제공.
- 시연 작성자 닉네임은 세션에서 자동 표시하며 사용자에게 로그인 요구 안 함.
- 화면 하단 주황색 기본 CTA: `등록`/`수정 완료`.

## UX·검증
- 빈 제목/본문과 카테고리 누락은 제출 차단. 서버가 동일 검증 수행.
- 제출 중 중복 탭 차단, 네트워크 재시도 시 클라이언트 idempotency key 사용 제안.
- 사진 권한 거부 시 텍스트만 작성 가능. 업로드 오류는 글 작성 전체 실패로 뭉개지 말고 재시도/사진 제거 제공.
- 작성 완료 → 생성된 글 상세로 이동. 수정 완료 → 기존 상세로 복귀.
- 뒤로가기 시 수정 중인 내용이 있으면 작성 포기 확인.
- 서버 응답으로 게시글 상태·이미지/작성자를 확인하기 전에 성공 화면을 표시하지 않음.

## QA
등록/수정/권한/업로드/키보드/취소/오류/초기화/작은 화면 및 접근성 포함. 실제 공개 업체 데이터에 변화를 주지 않음.
