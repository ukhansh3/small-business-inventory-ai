# UI-COMMUNITY-DETAIL-001 — 게시글 상세 및 댓글

**확정:** C-04~C-07, C-09, C-10. `/community/[postId]`는 제안 Expo Router 경로; 실제 경로는 구현 전 라우팅 표와 일치시킨다.

## 배치
- 상단: 뒤로가기 + `게시글` 제목, 우측 본인 글인 경우 더보기(수정/삭제).
- 메타데이터: 분류 칩, 자동 닉네임, 작성 시각(수정됐을 경우 수정 표시), 가격 제보일 경우 `공식 가격 아님`.
- 본문: 제목 전체, 본문 전체, 사진 원래 비율에 맞춰 노출(원본 검증된 storage 링크), 화면 가로폭 초과 금지.
- 반응: 좋아요 토글/개수, 저장 토글, 신고 버튼. 관리자 역할일 때만 별도 숨김/삭제 메뉴.
- 댓글: 시간순 목록, 닉네임·작성 시각·본문, 내 댓글은 수정·삭제. 대댓글 UI/답글 버튼 금지.
- 하단 입력: 댓글 입력 필드 + 등록. 키보드가 입력창 가리지 않음; 비어 있거나 너무 긴 내용 전송 금지.

## UX 흐름
- 저장/좋아요 토글은 피드와 상세에서 같은 DB 결과를 공유. 완료 전 재차 클릭 중복방지.
- `내 게시글 수정`: 기존 제목/본문/카테고리/이미지 미리채움 → 유효성 검사 → 성공 시 상세 갱신.
- `내 게시글 삭제`: 확인 대화상자 → 삭제 → 피드로 복귀. 공개하지 말아야 할 글이 저장 목록에 잔존하지 않음.
- 신고: 사유 입력/선택 → 접수 완료/중복 안내. **신고했다는 이유만으로 자동 숨김 처리하지 않음**, 승인된 관리자 조치 후 숨김.
- 숨김·삭제된 상세 URL: 본문/사진/댓글 노출 없이 `게시글을 볼 수 없습니다.` 표시.
- 댓글 작성/수정/삭제 실패: 즉시 오류와 재시도/취소, 서버 상태와 불일치한 숫자 그대로 유지하지 않음.

## 필수 상태
`loading`, `ready`, `empty comments`, `posting comment`, `edit`, `deleted/hidden`, `forbidden`, `network error`, `demo session expired`.

## 수용 기준
- 본인 이외 수정/삭제 불가(서버 권한 확인 필수), 관리자 조치 실제 업체에 영향 없음.
- 글/댓글/반응/사진의 세션 권한 일치, 수정/삭제 후 피드 및 저장 탭과 상태 동기화.
