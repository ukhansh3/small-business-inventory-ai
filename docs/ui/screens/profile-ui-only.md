# UI-PROFILE-001 — 내 정보 (데모 UI 전용)

**상태:** 화면 표시만 이번 데모. 신규 업체 관리 요청/DB 저장 없음.

## 와이어프레임
```text
┌────────────────────────────────┐
│ 천하장사                       │
│ 내 정보                        │
│ [시연 중]  시연 사장님          │
│                                │
│ 내 업체 관리                   │
│ ┌────────────────────────────┐ │
│ │ [예시] 아주 식자재           │ │
│ │ 등록된 업체 화면 미리보기     │ │
│ └────────────────────────────┘ │
│ [업체 등록 · 준비 중]           │
│ [업체 수정 · 준비 중]           │
│ [승인 상태 · 준비 중]           │
│                                │
│ 안내: 실제 신청/승인은 미지원   │
│ 지도 AI 커뮤니티 저장 [내 정보] │
└────────────────────────────────┘
```

## 명세
- 목업 색감(흰색 배경/검정 본문/주황 강조), 동일 5탭 사용. 정식 가입/로그인/로그아웃 버튼은 현재 데모에서 배제.
- 시연용 업체 예시는 **반드시 샘플 표시**; 기존 운영 DB의 업체 등록/승인 정보를 데모 승인 이력처럼 오인시키지 않는다.
- 준비 중 버튼은 비활성 스타일과 설명 텍스트를 함께 둔다. 누를 수 있는 경우에도 실제 등록/저장/심사 API 호출 없이 안내만 제공.
- 정식 사용자 프로필 항목(계정 ID, 개인정보 입력 등)은 UI 사전 설계만 가능하며 데모에 개인 데이터 수집 추가 금지.
- 다른 탭은 실제 기능. 내 정보의 UI 전용 정책을 지도·AI·커뮤니티·저장에 확장하지 말 것.

## 수용 테스트
1. 화면과 하단 5탭 정상 렌더 및 이동.
2. 내 정보에서 신규 업체 등록·수정·승인 API 요청이 발생하지 않음.
3. 실제 DB 운영업체·리뷰 이력 변경 0건.
4. `준비 중` 안내 및 시연용 데이터 라벨이 명확함.
5. 기존 구현 코드/마이그레이션이 무단 삭제되지 않음.
