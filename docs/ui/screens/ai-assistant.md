# UI-AI-ASSISTANT-001 — AI 도우미 채팅 화면

- **상태:** 사용자 AI-01~AI-10 요구 승인 / 시각 토큰·컴포넌트 일부 구현 제안
- **목업:** 사용자가 제공한 3개 스마트폰 스크린샷의 **중앙 AI 도우미 화면**을 기준으로 한다. 흰 배경, 검정 텍스트, 주황 강조; 상단 타이틀, 채팅 말풍선, 업체 추천 카드, 하단 입력창 및 5탭.
- **현재 상태:** `apps/mobile/src/app/(tabs)/assistant.tsx`는 키워드 기반 데모 미리보기다. 실제 채팅/AI/API는 아직 없다.

## 화면 구성 (위 → 아래)
1. **안전 영역 상단:** `AI 도우미` 제목, 현재 검색 지역 안내(가능할 때), 대화 초기화는 시연 세션 초기화 정책과 일관되게 처리.
2. **메시지 스크롤:** 사용자 메시지는 주황 계열 말풍선, AI 메시지는 밝은 중립 배경/검정 텍스트. 예: `근처에 양파 10kg 배송되는 곳 찾아줘`.
3. **답변 카드:** AI 메시지 아래에 업체별 추천 카드. 업체명, 품목/규격, 가격, 부가세, 배송비·조건, 가격 확인일, 명확한 자료 출처, `지도에서 보기` 버튼.
4. **작성 영역:** 텍스트 입력창, 전송 아이콘/버튼. 키보드 표시 시 입력창이 가려지지 않아야 함.
5. **하단 고정 네비게이션:** `지도 / AI 도우미 / 커뮤니티 / 저장 / 내 정보`. 현재 4탭 UI는 구현 변경 필요.

## UI 와이어프레임 (구조 예시)
```text
┌────────────────────────────────────┐
│ AI 도우미          검색 지역: 아주대 주변  │
├────────────────────────────────────┤
│                     [양파 10kg 배송?] │  사용자
│                                    │
│ [검색 결과를 찾아봤어요.]              │  AI
│ ┌────────────────────────────────┐ │
│ │ 아주 식자재   [시연용/실제 표기]   │ │
│ │ 양파 10kg       18,000원       │ │
│ │ 배송비: 미확인 · 확인일: ...      │ │
│ │ [지도에서 보기]                 │ │
│ └────────────────────────────────┘ │
│ ┌────────────────────────────────┐ │
│ │ (다른 확인된 업체 결과 카드)      │ │
│ └────────────────────────────────┘ │
├────────────────────────────────────┤
│ [메시지를 입력하세요...]       [전송] │
├────────────────────────────────────┤
│ 지도  AI 도우미  커뮤니티  저장  내 정보 │
└────────────────────────────────────┘
```
예시는 **UI 설명용 가상 값**이며 실제 AI 응답 또는 업체 데이터가 아니다.

## 이벤트와 데이터 바인딩
| 액션 | 기대 결과 | 실패/예외 |
|---|---|---|
| AI 탭 진입 | 현재 시연 세션의 대화 복원; 지역 컨텍스트 안내 | 세션 만료 시 새 세션 안내 |
| 메시지 입력 | 키보드가 올라오고 전송 버튼 상태 갱신 | 공백만 입력 시 전송 비활성 |
| 전송 | 사용자 메시지 표시, 응답 로딩, AI 메시지·업체 카드 추가 | 오류 시 전송 재시도/오류 표시; 중복 제출 방지 |
| 업체 카드 `지도에서 보기` | 지도 탭, 선택 업체 위치 강조 및 선택 업체 하단 카드 | 좌표 없음/업체 비공개 시 안내 |
| 카드 `업체 상세`(추가하는 경우) | 해당 업체 상세로 이동 | 숨김/삭제된 업체는 유효성 확인 |
| 마지막으로 적용된 지도 지역 변경 | 새 질문부터 새 적용 범위 사용; 과거 메시지의 근거/지역은 보존 | 과거 카드를 현 지도 위치로 재해석하지 않음 |
| 시연 초기화 | 대화/시연 쓰기 데이터 초기화 | 실제 공개 업체/승인 데이터 변경 금지 |

## 제품 정책 / 표시 유의사항
- 모델이 '배송 가능'이라고 단정하지 않도록 데이터가 제공하는 상태를 분리한다. 배송비 미확인 ≠ 무료.
- 다른 규격의 품목 가격을 비교할 때는 비교 불가 안내 또는 조건 기준을 명확히 표시한다.
- 업체와 가격은 서버가 검증한 데이터에서만 읽는다. 모델 자연어 문장의 금액을 화면 카드의 사실 데이터로 쓰지 않는다.
- 실제 업체와 가상 시연 업체를 결과 카드에서 명확히 구분. 정확하지 않은 과장된 '최저가' 문구 금지.
- 대화/검색 실패 상태, 로딩 중 자동 스크롤, 긴 응답, 네트워크 재시도, 카드 많은 경우 스크롤을 구현한다.
- 시연 앱에는 별도 로그인 장벽이 없으나 서버 세션/권한 검증이 없어도 된다는 뜻은 아니다.

## 반응형·접근성
- 작은 화면/큰 글씨/키보드·안전 영역에 대응. 메시지 입력창이 하단 탭에 가려지지 않아야 함.
- 화면 읽기 도구에 발신자, 업체명, 가격, 출처, 버튼의 의미를 제공. 로딩/실패 상태의 접근성 알림 고려.
- 필수 컨트롤은 적절한 터치 영역 확보. 주황색 위의 흰 글자 대비 확인.

## 연결 계약과 미정
- `POST /api/v1/ai/messages` 제안 계약: `docs/api/ai-assistant/post-messages.md`.
- 채팅 기록의 실제 저장 위치·방식, 모델/스트리밍, 크기별 배치/스크롤, 추천 카드 개수 상한은 후속 기술 설계.
- UI 색상 HEX는 목업 기준 후보와 실제 디자인 토큰 승인 간 차이가 있을 수 있다. 이미 승인된 **검정 텍스트 + 주황 강조** 방향을 유지.
