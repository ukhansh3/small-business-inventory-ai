# UI-COMMUNITY-001 — 사장님 커뮤니티 피드

**확정:** C-01~C-10 / 사용자가 제공한 천하장사 3화면 목업을 우선. **현황:** 현재 `community.tsx`는 2개 정적 글만 노출. 본 UI는 목표 설계로 아직 미구현.

## 화면 구조 (상단 → 하단)
1. **상단 헤더:** `사장님 커뮤니티` 검은색 강조 텍스트. 흰 배경, 주황색 브랜드 포인트. 가상 시연 글과 공식 업체 가격 정보가 혼동되지 않도록 문구 제공.
2. **카테고리 칩:** 좌→우 `전체`, `구매처 질문`, `가격 제보`, `거래 경험`. 현재 선택 칩은 주황 계열 강조. `전체` 기본 선택. 가로폭이 좁을 때 칩 수평 스크롤, 텍스트 자르지 않음.
3. **피드 카드:** 카테고리 배지(선택 가능 여부 없음), 자동 닉네임·작성 시각, 제목, 본문 2~3줄 요약, 사진 미리보기(있을 때), 댓글수/좋아요수/저장 토글. 카드 탭 시 상세 진입. 최신순 기준.
4. **주황 글쓰기 FAB:** 우측 하단, 고정된 하단 탭 위에 배치. 클릭 시 `/community/compose`. 화면 안전영역·키보드·스크롤과 겹치지 않음.
5. **하단 고정 5탭:** 지도 / AI 도우미 / 커뮤니티(활성) / 저장 / 내 정보. 제품의 공통 내비게이션을 재사용.

## 상태/상호작용
- 첫 진입: 로그인 없이 자동 시연 닉네임/세션 준비. 늦어질 때는 로딩, 실패 시 재시도 노출. 빈 목록을 오류로 오인하지 않음.
- 카테고리 탭: 필터를 바꾸면 페이지 cursor 초기화, 이전 요청 취소/무효화, 최신 게시글 로딩.
- 무한 스크롤: 추가 페이지 로딩, 마지막 페이지면 종료. 새 글이 생겨도 같은 카드가 두 번 나타나지 않음.
- 좋아요/저장: 현재 시연 계정의 상태를 표시하고 서버 성공 여부와 동기화, 실패시 시각 상태 원복/재시도.
- 이미지 탭: 글 상세의 이미지 보기로 이동. 외부 URL 직접 신뢰하지 않음.
- 카드 탭: 글 상세. 게시글 숨김/삭제되었다면 접근 불가 안내와 목록으로 이동.
- 피드 새로고침: 최신순 첫 페이지부터 새로 조회.
- 빈 상태: `아직 게시글이 없습니다` + 글쓰기 제안. 카테고리 비어 있으면 `해당 카테고리 글이 없습니다`.
- 오류/오프라인: 로딩 실패/시연 세션 만료를 별도로 표시, 재시도 제공. 타인 자료 섞기/임의 샘플로 대체 금지.

## 디자인 원칙
- 목업의 **흰색 배경 + 검은색 기본 텍스트 + 주황색 주요 동작 + 회색 보조 텍스트** 유지. 기존 코드의 남색 계열 `colors.ink`를 UI 정본으로 무단 고정하지 않는다.
- 본문·버튼은 터치/스크린리더 접근성, 최소 터치영역 44pt 수준 권장(구체 픽셀은 디자인 시스템에서 조정).
- 가격 제보 글에는 `사용자 제보 · 공식 가격 아님`을 명확히 표시. 일반 리뷰/문의도 시스템 생성 공식 데이터처럼 보이지 않게 구분.
- 바텀탭은 지도 화면의 하단시트 동작과 충돌하지 않음.

## UI 수용 테스트
- 4칩 표시/선택, 최근 글부터 안정 순서, 스크롤 페이지 로딩, 글쓰기 FAB, 상세 이동, 좋아요/저장 카운트 동기화.
- 5탭 내비게이션과 키보드/사진 권한/화면 작은 기기에서 버튼 겹침 없음.
- 작성자 닉네임이 동일해도 다른 actor의 글 수정 버튼을 노출·실행하지 않음.
- 숨김 글/이미지/좋아요가 피드에서 노출되지 않고, 새로운 시연 시작 후 이전 글이 사라짐.
