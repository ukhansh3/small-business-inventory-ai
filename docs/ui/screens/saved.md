# UI-SAVED-001 — 저장 탭

**상태:** S-01~10 UX 승인, 앱 개발 전 UI 명세. 레퍼런스: 사용자 제공 천하장사 목업의 흰 배경·검정 텍스트·주황 포인트.

## 화면 레이아웃
```text
┌──────────────────────────────────┐
│ 천하장사                     알림 │
│ 저장한 항목                       │
│ [전체]  [업체]  [게시글]            │
│                                  │
│ ┌──────────────────────────────┐ │
│ │ 업체  [북마크 ●]              │ │
│ │ 업체명 / 유형                 │ │
│ │ 주소 · 최근 정보 확인일        │ │
│ └──────────────────────────────┘ │
│ ┌──────────────────────────────┐ │
│ │ 게시글 [북마크 ●]             │ │
│ │ 제목 / 카테고리                │ │
│ │ 시연 닉네임 · 작성일           │ │
│ └──────────────────────────────┘ │
│                                  │
│ 지도  AI  커뮤니티  [저장]  내정보 │
└──────────────────────────────────┘
```

## 컴포넌트 규칙
- 상단 제목 `저장한 항목`; 세그먼트 `전체 / 업체 / 게시글` (기본 전체).
- 기본 정렬은 최근 저장한 순. 업체·게시글 카드를 서로 다른 아이콘/메타데이터로 구분하고 전체 탭에서는 시간순 혼합.
- 업체 카드에는 업체명·유형·주소·최근 확인일. 실제/가상 데이터 출처가 있는 경우 오해 없도록 가상 라벨 표시. 가격은 필수 정보가 아님.
- 게시글 카드에는 제목·카테고리·작성자 시연 닉네임·작성일. 삭제/숨김 시 원본 문구·이미지 표시 금지.
- 북마크는 저장 상태 표시와 저장 해제를 모두 수행; 클릭 영역 최소 44pt 권고, 스크린리더 `저장 해제` 등 접근성 레이블.
- 카드 본문 탭은 각각 `/vendor/[id]`, 커뮤니티 게시글 상세로. 저장 해제 탭과 카드 이동은 이벤트 충돌 없이 구분.
- 하단 5탭(지도, AI 도우미, 커뮤니티, 저장, 내 정보) 중 저장 선택 강조색 주황.

## 상태별 화면
| 상태 | 표시 |
|---|---|
| 최초 진입 | 목록 스켈레톤/로딩, 데이터 완료 시 목록 |
| 저장한 것 없음 | `아직 저장한 항목이 없어요` + `지도에서 업체 찾기` 안내 |
| 업체만 없음/게시글만 없음 | 해당 분류 빈 상태 안내, 다른 탭에 있는 저장은 유지 |
| 저장 요청 중 | 버튼 중복 탭 방지, 성공 시 동기화; 실패 시 이전 상태 복구 + 안내 |
| 데이터 로딩 실패 | 오류 메시지 + 다시 시도 |
| 삭제/숨김 자료 | `현재 볼 수 없는 항목` 최소 표현, 상세 이동 차단, 원본 내용 없음 |
| 새 시연 시작 | 모든 탭 비어 있는 새 세션 상태로 교체 |

## API 매핑 및 테스트
- 목록: `GET /api/v1/saved?type=...`; 업체 토글: `PUT/DELETE /api/v1/saved/vendors/{id}`; 게시글 토글: 기존 커뮤니티 `PUT/DELETE /api/v1/community/posts/{id}/save`.
- 저장 탭과 지도/상세/게시판 상태 동기화; 20개 초과 cursor 페이징; 필터 변경 시 목록 초기화.
- 하단 키보드/안전 영역 대응, 다크 모드 강제 반전으로 검정 텍스트 사라짐 금지. HEX는 디자인 시스템에서 최종 확정할 때까지 근사치.
- `main`에는 저장 탭 컴포넌트가 아직 없으므로 이 문서만으로 동작한다고 표기하지 말 것.
