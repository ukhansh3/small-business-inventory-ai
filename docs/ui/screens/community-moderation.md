# UI-COMMUNITY-MODERATION-001 — 시연 관리자 신고 처리

**확정된 제품 목표:** C-09. 관리자 기능은 실운영 staff 권한과 분리된 **현재 시연 전용 관리 뷰**로 설계.

- 신고 큐: 처리 전 접수 건을 최신순으로 표시. 제보 사유, 작성자 닉네임, 게시글 제목/본문을 표시.
- 게시글 검토: 신고 대상 게시글 확인, `숨김`, `시연 데이터 삭제` 버튼. 각 조치에 확인/사유 입력.
- 처리 결과: 게시글/이미지가 일반 피드·상세·저장 목록에서 보이지 않으며, 감사 기록은 현재 시연에만 저장.
- 일반 사용자: UI 버튼 없음 + API 수준의 접근 거절. 관리자 UI 표시 여부만으로 관리자 권한 결정 금지.
- 로그인 없는 데모에서 시연 운영자 역할을 어떤 방식으로 안전하게 활성화할지는 공통 시연 세션 기술 정책에서 정할 것. 공유 비밀을 클라이언트 코드에 박아 두거나 운영 DB의 `staff_roles`를 조작하면 안 된다.
- 새 시연 시작: 신고 큐, 숨김/삭제 상태, 데모 관리자 이벤트 초기화.
- QA: 타 시연/실제 업체/실운영 staff 데이터에 대한 조치 0건 보장.
