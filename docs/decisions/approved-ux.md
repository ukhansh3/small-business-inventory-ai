# 최신 사용자 승인 UX 기준 (2026-11-04)

> 이 문서는 `DECISIONS.md`의 최신 확정 항목을 읽기 쉬운 정본으로 추린 것. 기존 역사 기록 삭제하지 않는다. API 경로·DB 물리 구조·AI 제공자·기술 수치 승인은 아님.

| 구분 | 확정 UX / 범위 |
|---|---|
| 진입 | 로그인 화면 없음. 내부 안전한 세션 발급/복구 자동 처리 |
| 하단 탭 | `지도 / AI 도우미 / 커뮤니티 / 저장 / 내 정보` |
| 스타일 | 흰 배경, 검정 제목/본문, 주황 강조. 남색 본문 아님 |
| 지도 | 지도 중심. 핀 선택 시 하단 카드, 스와이프 업 시 업체 목록 |
| 기본 시트 | 첫 실행 시 접힌 결과 요약바. 펼친 높이 약 85% |
| 핀 가격 | 검색 전 업체명. 품목 1개 일치 시 품목·가격, 2개 이상 일치 시 `일치 품목 N개` |
| 클러스터 | 묶음 숫자 = 업체 수. 선택 시 확대, 검색 API 자동 호출 없이 `이 지역 검색` 노출 |
| 지도 검색 | 지도 이동·줌 시 재조회 안 함. `이 지역 검색` 탭 시 실제 가시 bounds로 검색 |
| 결과 | 지도는 현재 적용된 영역의 전체 일치 업체, 하단 목록은 20개씩 추가 로딩 |
| 정렬 | 기본 지도 중심 거리순, 품목 검색 시 가격순 옵션(비교 규격 미확정) |
| 초기 위치 | 허용된 GPS, 아니면 아주대 근처(기본 위치임을 명시) |
| 검색 이벤트 | 키보드 검색 제출 후 조회. 업체 유형/품목/배송 필터. 0건·오류는 분리 |
| 업체 상세 | 이름/유형/주소/영업/연락, 규격·가격·세금·배송·최소 주문·확인일, 저장/전화/지도 이동 |
| AI | **실제** LLM+서버 업체 검색, 구조화한 조건, 비교 가능할 때만 가격 비교, 근거 카드·지도 연동, 시연 세션 대화 유지 |
| 커뮤니티 | 전체/구매처 질문/가격 제보/거래 경험, 글/사진/댓글/좋아요/저장/신고 및 시연 관리자 |
| 저장 | 업체+게시글, 전체/업체/게시글, 최근 저장순, 재선택 해제, 삭제·숨김 데이터 내용 비노출 |
| 내 정보 | **UI 전용**; 새 업체 등록·수정·운영자 승인 백엔드 구현은 이번 데모 제외 |
| 데이터 | 공개 실제 업체는 읽기 전용, 가상/게시글/AI/저장은 시연 세션 격리, 새 시연 시작 시 해당 세션 데이터 초기화 |
| 주문 | 주문·결제·정식 OAuth·실시간 가격/재고 보장 제외 |

## 추가 제품 승인 없이 구현 완료로 간주할 수 없는 기술 현안
- 정식 데이터 출처 경계, demo 프로젝트/DB 격리 인프라, 세션 시작·초기화 트리거, API 실제 인증·RLS.
- 지도 범위 최대 크기, 전체 지도 조회 성능 방식, 가격순 비교 단위·배송비 포함 산식.
- 모델 제공자/예산/호출 제한, 시연 계정/관리자 안전 정책, 이미지 라이선스/업로드 허용.

이 현안은 한 번에 모아 사용자/팀에 확인할 것. 임의 구현 결정 금지.

## 개발 범위 추가 승인 (2026-11-04)
기존 Supabase DB는 반드시 계속 연결해서 사용한다. 이전/초기화는 금지한다. 기존 앱 코드 재사용은 선택이며 새로 작성 가능하다. 작업 브랜치는 `dev`이며 `main`을 병합/수정하지 않는다. `docs/handoff/DEV-SCOPE-OVERRIDE.md`가 이 범위의 정본이다.
