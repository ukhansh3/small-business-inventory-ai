# ADR-011: 아주대 반경 8km 시연 및 현재 위치 지도

- 상태: 수용
- 날짜: 2026-11-04

사용자가 공공데이터 업체 8곳 삭제와 가상 업체 200곳의 아주대 주변 재배치를 요청했다. 최종 반경은 8km다. ADR-009의 공공 업체 시연 화면·조회 API를 중단하고, ADR-010의 가상 업체 전용 테이블을 유지한다. 공공 업체 DB 삭제는 서버 키의 DELETE 권한 부족으로 관리자 SQL 실행이 남아 있다.

가상 업체 위치는 아주대 반경 8km 안에서 만들며 가까운 곳에 더 많이 배치한다. 지도는 위치 권한을 허용하면 현재 위치를 기준으로 열고, 실패·거절하면 아주대를 사용한다. 사용자의 위치는 기기에서만 지도 기준점으로 사용하며 DB에 저장하지 않는다. 지도 확대·축소는 유지하고, 검색 필터를 바꿔도 사용자가 조절한 지도 위치·배율을 다시 맞추지 않는다.
