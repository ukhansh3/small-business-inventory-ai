# ADR-010: 지도형 공급업체 탐색을 제한된 MVP 실험으로 명시

- 날짜: 2026-11-04
- 상태: 팀 검토안 / 미채택
- 작성 브랜치: `차승호`
- 관련 결정: ADR-004, ADR-006~009

## 배경

ADR-004는 인터뷰 근거가 부족한 지도와 공개 커뮤니티를 핵심 범위에서 제외했습니다. 이후 팀은 Expo 모바일 앱, 카카오 지도, 업체 직접 등록·운영자 승인, 공공업체 시연 데이터를 구현했습니다. 구현했다는 사실만으로 지도·커뮤니티의 사용자 수요가 검증된 것은 아니며, 이전 결정이 바뀐 이유도 별도 ADR에 기록되지 않았습니다.

## 제안 결정

팀 승인 시 다음처럼 범위를 해석합니다.

1. 지도·목록 기반 공급업체 탐색은 **사용 행동과 데이터 비교 가능성을 검증하는 제한된 MVP 실험**으로 유지합니다.
2. 핵심 실험은 `조건 입력 → 승인 업체 목록·지도 → 상세 조건 확인 → 후보 선택`입니다.
3. 업체 등록·revision·운영자 검토는 검색 데이터를 유지하기 위한 P0 운영 흐름으로 둡니다.
4. AI 도우미와 커뮤니티는 P1로 유지하며 샘플 화면을 실제 기능이나 검증된 요구로 표현하지 않습니다.
5. 공공업체 `mvp_demo`는 UI·데이터 파이프라인 시연용이며 문제 가설의 사용자 근거로 사용하지 않습니다.

이 결정이 채택돼도 ADR-004의 당시 인터뷰 판단을 지우지 않습니다. 지도 수요가 확인됐다는 결정이 아니라, 제한된 실험을 수행한다는 제품 결정입니다.

## 실험 성공·중단 조건

### 계속 조건

- 사전 등록한 데이터 비교 가능성 스파이크를 통과합니다.
- 사용자 테스트에서 참가자가 출처·규격·가격·배송을 근거로 후보를 선택합니다.
- 목록과 지도 중 하나가 선택 행동에 실제로 사용됩니다.

### 축소·중단 조건

- 비교 가능한 Offer 데이터를 유지할 수 없습니다.
- 참가자가 지도 대신 기존 연락처·검색만 사용하며 추가 가치가 관찰되지 않습니다.
- 데이터 최신성·출처 경고 때문에 후보 선택이 불가능합니다.
- 인터뷰 사전 기준 적용 결과 H1-b가 폐기 조건에 해당합니다.

## 결과

- 문제 온톨로지는 공급업체 판단 과정을 설명하고 지도·API 스키마를 포함하지 않습니다.
- SPEC은 지도형 탐색을 제품 실험으로, AI·커뮤니티를 P1로 표시합니다.
- 기능 구현과 사용자 문제 검증 상태를 구현 현황에서 분리합니다.
- 팀 승인 전 이 ADR을 채택된 결정으로 인용하지 않습니다.
