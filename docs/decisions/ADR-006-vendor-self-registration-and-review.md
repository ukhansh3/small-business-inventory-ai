# ADR-006: 업체 직접 등록과 운영자 검토 후 공개

- 날짜: 2026-10-28
- 상태: 사용자 명시 결정. 세부 스키마와 API 계약은 설계·검토 전.

## 결정

공급업체 사장이 자신의 업체를 직접 등록한다. 운영자 확인 후 공개하며, 업체마다 품목과 가격을 반드시 등록한다. 기존 샘플 가격 검색 중심 설명을 이 등록 흐름에 맞게 수정한다.

이는 제품 해결책의 선택이며 인터뷰로 수요가 검증되었다는 뜻은 아니다. `docs/product/problem-statement.md`의 문제 검증 상태는 유지한다.

## 범위와 미결정 사항

DB 규칙 설명서는 `docs/database/업체등록_DB규칙_설명서.txt`에 작성한다. 제출본 분리, 수정 재승인, 권한·필수값·트랜잭션은 설계 제안이며 실제 migration이나 정책을 적용하지 않는다. 업체 증빙, 비로그인 공개 여부, 가격 변경 검토 중 노출 정책은 별도 결정한다. 구현 전 SPEC·ontology·공용 계약과 승인 범위를 정합화한다.
