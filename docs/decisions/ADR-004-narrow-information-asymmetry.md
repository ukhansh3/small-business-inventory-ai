# ADR-004: 정보 비대칭 가설을 좁혀 다시 검증한다

- 상태: 채택
- 근거 범위: 현재 내용 확인을 마친 `I01`~`I06`, `I09`, `I10`

## 결정

현재 문제를 `초보 사장님을 위한 종합 정보 공유 플랫폼`으로 확정하지 않습니다. 대신 익숙하지 않은 품목·거래처·외부업체를 판단할 때 기존 경험과 연락처가 부족해 생기는 탐색 문제로 범위를 좁힙니다.

첫 MVP를 정하기 전까지 중고거래, 지도, 공개 커뮤니티는 검증되지 않은 아이디어로 분리합니다. 가격만 비교하지 않고 품질, 배송 속도, 최소 주문량, 거리와 긴급 대응 조건을 함께 다뤄야 하는지도 확인합니다.

## 근거

- 가격 차이를 뒤늦게 알고 폐유 수거업체를 바꾼 사례와 수리업체 탐색에 시간이 든 사례가 있었습니다.
- 업계 지인, 가족 소개, 저장한 명함과 과거 거래 경험이 업체 탐색을 빠르게 만든 사례가 있었습니다.
- 경험이 많은 점주는 새 거래처를 하루 안에 정했고, 변경 자체가 어렵지는 않다고 말했습니다.
- 가격을 비교하더라도 신선도, 배송, 품질, 무거운 물품 운반 때문에 최저가만 선택하지 않았습니다.
- 경쟁 관계인 주변 점주와 거래처·가격을 거의 공유하지 않는다는 반대 근거가 나왔습니다.
- 실제 표본에는 장기 운영 점주도 포함돼 `개업 3년 이내`만으로 사용자를 정의할 수 없었습니다.

## 영향

- `초보 사장님`은 확정 사용자 정의가 아니라 비교할 세부 집단으로 둡니다.
- 점주가 가격을 자발적으로 공개한다는 전제를 제품의 핵심 구조로 사용하지 않습니다.
- 중고거래와 지도는 해당 행동이 추가 인터뷰에서 확인되기 전까지 구현 범위에서 제외합니다.
- `I07`, `I08`, `I11`의 내용 확인이 끝나면 이 결정을 다시 검토합니다.

## 다음 판정 질문

1. 낯선 거래처나 외부업체를 찾은 최근 사건이 몇 건인가?
2. 그 사건에서 실제로 쓴 시간, 연락한 업체 수와 금전 손실은 얼마인가?
3. 기존 경험이나 지인이 없었다면 판단이 얼마나 어려웠는가?
4. 가격 외에 반드시 비교해야 할 조건은 무엇인가?
5. 점주가 정보를 제공하지 않아도 유지할 수 있는 데이터 출처가 있는가?
