# ADR-007: Android·iOS 공통 모바일 앱으로 전환

- 날짜: 2026-10-28
- 상태: 사용자가 모든 휴대폰 기종 호환을 요청하여 Android/iOS 공통 앱 방향을 명시했다. 개별 기종 호환 검증과 출시 승인은 별도다.

## 결정

사용자 화면의 개발 기준을 apps/mobile의 React Native·Expo로 전환한다. 기존 Next.js 화면을 Java WebView로 감싼 APK를 장기 개발 기준으로 삼지 않는다. 앱은 네이티브 컴포넌트와 Expo Router를 사용한다. 카카오 지도는 기존 JS SDK를 유지하기 위해 지도 영역만 전용 HTTPS 페이지와 WebView로 격리한다.

## 기존 가이드와 관계

기존 Next.js/Tailwind/shadcn 웹 UI 고정 규칙은 모바일 화면 범위에서 이 ADR과 apps/mobile/DEVELOPMENT_GUIDE.md로 대체한다. 기존 웹 소스는 보존하고 지도·향후 서버 지원용으로 구분한다. 서버 지오코딩은 모바일에 이식하지 않는다. 서비스 역할 키와 OpenAI 키를 설치 파일에 넣지 않는다. 세부 API 계약·DB migration·인증/RLS는 이번 전환에서 변경하지 않는다.

## 사용자 흐름

업체 직접 등록, 품목·가격 필수, 운영자 확인 후 공개는 ADR-006을 따른다. 이번 등록 화면은 저장하지 않는 폼 미리보기다. 실제 제출·운영자 화면·DB 승인 처리는 추후 계약과 함께 구현한다. 사용자 수요가 검증되었다는 뜻은 아니다.

## 영향과 한계

양 플랫폼 코드와 빌드 설정을 함께 관리해야 한다. 모든 오래된 OS·기기 지원을 약속하지 않는다. 지원 범위는 SDK와 실제 빌드·기기 검증으로 확인한다. 기존 /phone 미리보기와 APK는 새 앱의 실행 결과를 보여주지 않는다. iOS 설치·스토어 배포는 별도 서명과 계정이 필요하다.
