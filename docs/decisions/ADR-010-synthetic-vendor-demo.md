# ADR-010: 가상 업체 200곳은 별도 시연 테이블로 관리

- 상태: 수용
- 날짜: 2026-11-04

## 결정

아주대 중심 50km 이내의 가상 업체 200곳은 `mvp_synthetic_vendors`에 넣는다. 승인된 실제 업체와 공공데이터에서 가져온 사업자 식별정보에는 넣지 않는다. 각 행은 `synthetic_demo`와 고정 안내문으로 가상 자료임을 표시하고, 로그인 사용자만 읽는다.

앱은 시연 전용 API에서 자료를 받아 검색·업종 필터를 제공한다. 업체 목록은 `FlatList` 가상화로 화면에 보이는 행만 그린다. 지도는 업체 좌표 범위에 맞춰 처음 화면을 잡고 확대·축소 버튼을 제공한다.

## 이유

가상 가격·상호·위치를 실제 업체가 제공한 정보처럼 보이게 하면 안 된다. 전용 테이블로 분리하면 운영 승인 데이터, 공개 공공데이터 자료와 섞이지 않는다. 200개를 한꺼번에 일반 `ScrollView`로 그릴 때의 불필요한 렌더링도 피한다.

## 제한

이 자료는 제품 탐색용 시연 데이터다. 실제 업체, 서비스 제공 여부, 가격·배송 약속을 뜻하지 않는다. 업종 목록은 시연을 위한 탐색 분류이며, 공공데이터의 공식 분류 전체라고 주장하지 않는다.
