# ADR-009 공공 업체 원문과 가상 거래 정보의 MVP 분리

- 날짜: 2026-11-04
- 상태: 사용자 승인 범위 구현·실제 DB 적재 완료
- 브랜치: 민균

사용자는 공공데이터의 실제 업체를 DB에 넣고, 업체 종류는 원문을 유지하며 가격·거래 조건은 임의의 MVP 시연 정보로 채우도록 요청했다. 실제 서비스 시나리오는 업체 사장 직접 등록을 유지한다. 인터뷰 관찰이나 업체 동의로 해석하지 않는다.

공공데이터 원문의 업체명·업종·주소·기준일·출처를 전용 `mvp_public_vendors`에 저장한다. 임의 가격·서비스·조건은 `demo_*` 필드와 고정 시연 경고로 분리한다. `vendor_verified=false`, `data_kind=mvp_demo`만 허용한다. 기존 승인 업체·가격·검토 이력에 편입하지 않고 앱에서 별도 ‘공공 업체 MVP 시연’ 화면으로 연결한다. 실제 사장 소유권이나 운영자 승인·업체 제공 가격으로 위장하지 않는다.

초기 가져오기는 공공데이터포털 3079598(경기도 광주시 전문건설업, 기준일 2026-03-06, 이용허락범위 제한 없음)의 8곳이다. 수원·아주대 업체로 주소를 바꾸지 않는다. 경기도 폐기물 자료는 제공 사이트 접속 차단으로 이번 가져오기에 포함하지 않는다. 원본 CSV·정확한 주소·전화번호·실제 키는 Git에 커밋하지 않는다. 공개된 사업장 주소는 요청된 Supabase에만 저장한다. 전화번호는 이번 시연에 가져오지 않는다.

DB 추가·조회 API·별도 시연 화면과 출처 표시를 구현한다. 로그인 공개 범위는 유지하고 일반 사용자는 시연 자료를 수정할 수 없다. 승인 업체 검색 계약은 유지한다. 일반 시나리오의 서비스 가격·견적형 입력 확장은 별도다.
