# ADR-005: 천하장사 앱 프로토타입 소스를 팀 저장소에서 공유

- 날짜: 2026-10-28
- 상태: 사용자 요청에 따른 소스 공유. 코드 리뷰와 제품 계약 승인은 별도.

## 결정

사용자가 앱 전체 소스를 기존 팀 저장소에 올리고 팀원별 브랜치로 작업하도록 명시적으로 요청했다. `apps/cheonhajangsa`를 공동 개발 기준 경로로 삼는다. 기존 인터뷰·문제 탐색 문서와 미커밋 자료는 보존한다.

## 범위

화면·가상 데이터·카카오 지도·서버용 주소 변환 모듈·Android 패키징 소스를 공유한다. 이는 원격 서버·DB 연동이나 P0 전체 완료를 뜻하지 않는다. 루트 SPEC/ontology와 앱 개발 가이드의 미승인 C1~C4 계약을 확정하지 않는다. 인터뷰 근거나 제품 수요를 새로 검증했다고 기록하지 않는다.

## 협업과 비밀정보

실제 키·`.env.local`·APK·서명 키·빌드 산출물은 제외한다. `.env.example`과 실행·브랜치·PR 가이드를 제공한다. 원격 main에 직접 push하지 않고 공유 브랜치와 PR을 사용한다. 팀원 권한 변경·초대는 이 작업에서 수행하지 않는다.
