- 상태: **제품 동작 승인(Q-DETAIL-01~08)** / API·DB 신규 변경 없음 / 프론트 일부 구현됨
- 범위: 지도 홈에서 업체를 선택하고 `업체 상세 보기`를 탭했을 때 확인하는 단일 업체 상세 화면
- 우선순위: 핵심 상세 조회 P0, 저장 버튼 연동은 저장 기능 P1과 함께 구현
- 연결: `docs/features/vendor-search.md`, `docs/ui/screens/vendor-detail.md`, `docs/api/vendor-search/get-vendor-detail.md`, `docs/database/vendor-detail.md`

## 사용자 흐름

1. 지도 핀 선택 → 하단 업체 카드 → `업체 상세 보기` 탭.
2. 업체 상세는 마지막으로 선택한 **업체 ID**를 기준으로 조회한다. 검색어가 있었다면 표시 우선순위 결정용 검색 컨텍스트를 함께 전달한다. 검색 컨텍스트가 없는 진입도 지원한다.
3. 업체 기본 정보와 취급 품목을 표시. 검색어에 일치하는 품목을 먼저 배치하고 그 외 공개 품목은 그다음에 보여준다. 검색어가 있다고 일치하지 않는 품목을 임의 삭제하지 않는다.
4. 저장 토글은 로그인 화면을 요구하지 않는 시연 사용자 세션에 연결하되, 실제 사용자 정보나 공개 업체 원본은 변경하지 않는다. 저장 기능의 상세 데이터 구조/동작은 별도 saved-vendors 명세가 정본.
5. 유효한 공개 전화번호가 있는 경우에만 기기 전화 앱 호출. 전화번호가 없으면 연락처 미확인 안내, 잘못된 번호로 임의 전화 금지.
6. `지도에서 위치 보기`는 지도 탭으로 돌아가 해당 업체의 좌표에 지도 카메라 초점을 맞춘다. 업체의 위치 좌표가 없는 데이터는 버튼을 비활성화하고 이유를 알린다.

## 데이터 및 표시 원칙

- 실제 공개 업체(`live`) 상세는 현재 승인된 공개 revision만 표시하고, 가격·배송 조건의 정확한 출처와 확인일을 유지한다.
- 가상/시연 업체(`synthetic_demo`, `mvp_demo` 등)의 가격·업체명·좌표는 **가상/시연 데이터**라는 표시를 항상 유지한다. 실제 업체가 승인했다는 표현 금지.
- `price=null` 또는 가격 미확인: `가격 문의` 등 미확인 문구. `delivery_fee=null`: `배송비 미확인`. 0원은 **서버가 명시적으로 0을 제공**했을 때만 무료로 취급. DTO와 맞지 않는 기존 실제 데이터 값을 임의 조작하지 않는다.
- 가격은 KRW, 수량·규격·포장 단위 표시를 함께 제공. 단위가 다르면 서로 바로 비교 가능한 가격으로 오인하게 표현하지 않는다.
- 배송 가능 여부와 배송비는 다른 의미. 배송 가능 여부만으로 무료 배송 또는 이용 가능 지역을 보증하지 않는다.
- 영업시간/연락처/설명 등 빈 문자열은 입력된 사실이 없음을 안내하고 빈 값 그대로 UI에 출력하지 않는다.

## 상태 / 실패 정책

- 로딩: 상세 화면 로딩과 뒤로가기 제공, 요청 중 중복 로딩 방지.
- 404/비공개 전환: `현재 공개된 업체 정보를 찾을 수 없습니다` + 지도로 돌아가기.
- 네트워크 오류: 재시도와 뒤로가기 제공. 오래된 데이터를 최신 실제 가격처럼 표시하지 않는다.
- 사진 없음: 빈 이미지 영역을 강제로 채우거나 가상 업체 사진으로 대체하지 않는다.
- 전화번호 없음·부정확: 전화 연결 금지, 안내 표시.
- 시연 데이터 초기화 후 상세 직접 링크: 존재하지 않으면 안내 + 지도로 돌아가기.

## 수용 테스트

- **DETAIL-AC01** 지도에서 선택한 vendor ID의 상세만 표시.
- **DETAIL-AC02** 이름/유형/주소/영업시간/연락처·품목/가격·세금/최소 주문/배송비/확인일 표현.
- **DETAIL-AC03** 검색어 일치 품목이 맨 위로 오며 다른 품목도 목록에 남아 있음.
- **DETAIL-AC04** 저장 토글은 시연 세션에만 쓰고 실제 공개 업체 본문은 수정하지 않음.
- **DETAIL-AC05** 전화번호 유효한 경우에만 `tel:` 링크 호출.
- **DETAIL-AC06** 지도에서 위치 보기 → 업체 좌표로 지도 이동, 상세에서 뒤로가기 정상.
- **DETAIL-AC07** 미확인 가격·배송비는 0원/무료로 변환되지 않음.
- **DETAIL-AC08** 가상 데이터는 실데이터로 오인되지 않도록 표시.
- **DETAIL-AC09** 주문·결제 CTA가 없음.
- **DETAIL-AC10** 404, 오류, 이미지 없음 시 사용자 재시도 또는 뒤로가기 경로 있음.

## 기존 코드 및 구현 필요 사항

- 현재 `apps/mobile/src/app/vendor/[id].tsx`는 승인 공개 상세·품목·영업시간·연락처·전화 기능을 일부 구현함.
- 아직 화면 목적에 맞는 **업체 저장**, **지도 복귀 후 업체 좌표 강조**, **검색어에 따른 품목 우선 배치**, **정교한 정보 누락 처리**, **다양한 시연 데이터 타입 통합**이 미구현 또는 연결 필요함.
- 현재 `GET /api/v1/vendors/{id}`는 실제 공개 업체용이며 Bearer 토큰 필요. 로그인 화면 없이 시연하려면 자동 세션/격리 데모 조회 설계가 선행되어야 함.
- `publishedVendorSchema.price`는 양수 필수. 따라서 **실제 공개 API가 null 가격을 반환할 수 있는 것처럼 계약을 바꾸지 않는다**. 가격 미확인 문구는 시연 데이터나 별도 승인된 DTO 확장 가능성에 대해 설계한다.
