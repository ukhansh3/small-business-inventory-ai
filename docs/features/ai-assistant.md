# FEAT-AI-ASSISTANT-001 — AI 도우미 (P1)

- **사용자 결정:** AI-01~AI-10 일괄 승인 (2026-11-04)
- **구현 상태:** 미구현. `apps/mobile/src/app/(tabs)/assistant.tsx`의 현행 화면은 **실제 AI가 아닌 샘플 키워드 검색**이다.
- **범위:** 대화로 업체·품목 탐색 → 검색 근거가 있는 비교 카드 → 지도/업체 상세 연동.
- **관련 명세:** `docs/ui/screens/ai-assistant.md`, `docs/api/ai-assistant/post-messages.md`, `docs/database/ai-assistant.md`, `docs/features/vendor-search.md`, `docs/features/vendor-detail.md`.

## 제품 흐름
1. 사용자가 지도에서 검색한 뒤 AI 탭에 들어간다. 마지막 **성공적으로 적용된 지도 영역(appliedBounds)**이 기본 지역이다. 지도 상태가 없다면 화면상 시연 기준 지역과 현재 GPS 유무를 분명하게 표시한다(지역 전달 구현 상세는 후속 계약).
2. 사용자가 '양파 10kg 배송되는 업체 찾아줘' 등을 보낸다. 빈 메시지는 전송할 수 없고 중복 전송을 방지한다.
3. **서버**는 사용자 요청에서 검증 가능한 검색 조건을 추출하고, 그 조건을 기반으로 **공개 가능한 승인 업체/명시적 시연 데이터**만 조회한다. LLM은 답변 설명·조건 해석에 사용하되 권한, 업체 ID, 가격을 결정하는 단독 신뢰원으로 사용하지 않는다.
4. 서버가 반환한 구조화된 검색 결과에서 비교 가능한 항목의 가격·규격·배송 조건을 카드로 보여준다. 품목/가격 근거가 없는 경우 '미확인' 또는 '결과 없음'이라고 안내한다.
5. `지도에서 보기`를 탭하면 해당 업체 좌표를 보여주는 지도로 이동해 업체를 선택한다. **AI 결과가 현재 지도 적용 영역 밖**인 경우 지도 카메라 이동과 `이 지역 검색` 동기화 정책을 지켜야 하며, 조회되지 않은 업체를 기존 영역의 검색 결과에 억지로 삽입하지 않는다.
6. 같은 시연 세션에서 이전 질문/답변을 유지한다. 새 시연 시작 시 대화·AI 관련 쓰기 데이터만 초기화한다.

## AI 검색·가격 표현 안전 제약
- 서버의 검증된 업체 DTO/정책에 없는 공급처, 가격, 할인가, 입고 가능 여부, 배송 가능 지역을 생성하지 않는다. AI가 추측한 값은 **절대** '업체 제공 가격'으로 보여주지 않는다.
- 비슷한 품목명과 서로 다른 수량(5kg vs 10kg), 포장 형태, 과세, 배송비는 동일 상품의 총액 최저순으로 무조건 정렬하지 않는다. 비교 불가능 시 카드만 나열하고 비교 불가 이유를 명시한다.
- 배송 가능 `fulfillment`는 업체의 일반 거래 방식이지 특정 주소 배송 보장이나 즉시 배송 가능성을 뜻하지 않는다.
- 가상 업체(`synthetic_demo`/`mvp_demo`)는 모든 결과 카드에 시연 출처 표시. 실제 승인 업체(`live`)는 원본과 출처·확인일 연결.
- LLM이 제안한 품목 이름은 검색 질의를 만드는 참고일 뿐, 구매/배송/업체 진위에 관한 보증으로 표기하지 않는다.
- 고객 전화번호/업체 주소 등 조회 가능 필드는 **공개 승인 데이터**에서만 전달. 숨김/심사 중 수정본, staff 메모, 타 사용자 시연 데이터는 절대 검색·모델 컨텍스트에 포함하지 않는다.
- 임의 업체 설명이나 커뮤니티 텍스트에 들어 있는 지시문을 AI의 상위 명령으로 따르지 않게 하고, 서버 조회 정책 및 금칙을 별도 강제한다.

## 로딩·오류·빈 상태
- 새 대화: 안내 문구와 질문 예시, AI 기능이 실제 연결되지 않았으면 연결 불가 상태를 정직하게 안내.
- 전송/응답 중: 작성 메시지는 먼저 나타나며 답변 대기/취소 또는 재시도 경로를 표시.
- 조회 결과 0건: 추천 업체를 꾸며내지 않고 '일치하는 업체를 찾지 못했습니다' + 수량/배송/지역 조건 변경 제안.
- AI 모델 장애: 서버의 업체 검색 성공 여부와 분리해서 모델 응답 장애를 안내. 근거 없는 자연어 답변 대신 검증된 검색 목록을 보여줄 수 있는 폴백은 **구현 제안**.
- 서버/검색 API 오류: '결과 없음'으로 오인하지 않고 재시도 제공.
- 데이터 초기화/만료: 기존 세션 메시지·카드 참조가 유효하지 않으면 새 시연 세션에 맞게 상태 초기화.

## 수용 테스트
- AI-AC01: 자유 텍스트 대화 2턴에서 '배송되는 양파' → '그중 10kg' 문맥 유지.
- AI-AC02: '양파 10kg 배송'에서 품목/규격/배송 의도가 추출되고 화면 근거가 표시됨. 모호한 조건은 확인 요청.
- AI-AC03: 마지막으로 **적용된** 지도 bounds가 검색 조건에 사용되며, 이동 중 미적용 bounds를 몰래 사용하지 않음.
- AI-AC04: 비교 카드의 업체 ID·가격·세금·확인일은 서버 근거 레코드와 일치.
- AI-AC05: 단위/배송/세금 등 비교 불가 조합에 대해 무조건 저렴한 순위를 생성하지 않음.
- AI-AC06: 지도에서 보기 탭 시 정확한 업체 ID와 좌표로 이동하고 선택 카드 표시.
- AI-AC07: AI 모델 미연결/키 누락이면 기능 미구현 또는 연결 오류로 표시; 샘플 응답을 실제 AI로 표시하지 않음.
- AI-AC08: 근거 없는 가격, 업체, 배송 가능 조건이 카드에 포함되지 않음. 가상과 실제 출처가 다르게 표시됨.
- AI-AC09: 결과 0건, 모델 장애, 네트워크 오류 각각 다른 상태/재시도 제공.
- AI-AC10: 동일 시연 세션에서 대화가 유지되고 새 시연에서 초기화됨. 타 시연 세션과 실제 DB 쓰기 데이터에 간섭 없음.
- AI-AC11: 서버에서 LLM 입력 크기/요청 빈도 제한·API 키 비노출·지시문 주입 대응 검증.
- AI-AC12: 추천 결과가 숨김/미승인 업체 또는 시연 전용 자료를 실제 업체로 둔갑시키지 않음.

## 기술 미결정/계약 갭 (제품 승인과 분리)
- LLM 제공자·모델·스트리밍 지원·호출량/비용 한도, 자연어에서 품목·규격·지역 의도 추출 알고리즘.
- `POST /api/v1/ai/messages` 등 **아래 API 경로는 제안**이며 `main`에는 존재하지 않음.
- 세션 발급/권한/RLS·초기화 트리거는 앱 전체 데모 세션 명세가 정본이 되어야 함.
- 업체 비교 가능성 검증 산식, 텍스트/카드 렌더링 규칙과 상세 지도 인터페이스.
- *미결정 세부값을 AI 에이전트가 임의로 최종 승인 처리하지 않는다.*
