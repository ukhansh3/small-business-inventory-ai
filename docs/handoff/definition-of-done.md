# 완성 판정 기준 (이번 데모)

**아래는 검증 계획이며, 아직 단 하나도 실제 이 ZIP에서 실행·통과했다고 주장하지 않는다.**

| 게이트 | 합격 기준 | 증거 |
|---|---|---|
| 문서 | 승인 정책, API, Zod, DB, UI 충돌을 PR에 기록 | PR 리뷰 링크 |
| 시연 로그인 UX | 로그인 페이지 없이 진입, 타 세션과 분리된 서버 인증 성공 | Android 에뮬레이터 녹화+API token 검증 |
| 지도 | 기본 요약시트·핀 카드·목록 20건·viewport 검색·전체 업체 클러스터·이 지역 검색 | 사용자 플로우 테스트/요청 캡처 |
| 업체 상세 | 세금·가격 확인일·배송 및 출처 표시, 전화/저장/지도 | 실데이터·시연데이터 각각 테스트 |
| AI | 실제 서버 LLM 호출, 근거 있는 서버 후보만 반환, 비교 불가 가격순 금지, 세션 다중턴 유지 | 모델 호출 로그(PII 마스킹)+hallucination 평가 |
| 커뮤니티 | 사진·글·댓글·반응·저장·신고·시연 moderation 동작 | API/RLS/E2E 테스트 |
| 저장 | 업체·글 저장/해제와 목록 동기화, 삭제/숨김 원문 비노출 | API/E2E 테스트 |
| 내 정보 | UI-only 노출, 미구현 버튼은 `준비 중`, 운영 업체 쓰기 0 | 화면 및 네트워크 trace |
| 보안 | 운영 승인 업체 쓰기 0, A/B 시연 격리, Storage/AI/신고 권한 검증, secret 유출 0 | 권한 회귀 테스트 |
| 리셋 | 새 시연만 해당 세션 행·Storage 정리; 타 세션/운영 불변 | DB 전후 데이터 비교 |
| 검증 | web build/typecheck/lint/tests, Expo Android 시뮬 실기기 가능한 범위, 수동 화면 스크린샷 | 실행 로그, 실패/skip 명시 |

추가 QA 체크: 검색 오류와 0건 구분, 신호 약한 네트워크, 좌표/날짜 경계, 페이지 21개 이상, 클러스터 과밀, 동시 동작, 계정 없이 시작, 강제 재시작 후 복구.
