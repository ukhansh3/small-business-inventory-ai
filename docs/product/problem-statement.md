# 현재 문제 정의

## 대상 사용자

익숙하지 않은 식자재, 거래처 또는 외부업체를 직접 찾아 비교해야 하는 소규모 자영업자입니다. 초기에는 개업 3년 이내 점주를 핵심 대상으로 가정했지만, 인터뷰 결과 업력만으로 문제를 구분하기 어렵다는 반대 근거가 나왔습니다.

## 문제 가설

해당 품목이나 업체에 대한 경험이 적은 점주는 적정 가격과 품질을 판단할 기준이 부족해 검색, 영업사원 접촉, 저장한 연락처 확인 또는 지인 문의에 의존할 수 있습니다. 경험과 인맥이 판단을 빠르게 만들 수 있지만, 이 문제가 얼마나 자주 발생하고 비용이 얼마나 큰지는 아직 검증 중입니다.

## 현재 관찰된 증거

- 주변 점주와 가격을 비교한 뒤 폐유 업체를 바꾼 사례
- 설비 고장 시 업체를 찾고 비교하는 데 시간이 많이 든 사례
- 관련 업계 지인의 도움을 받아 식자재 거래처를 고른 사례
- 기존 업계 경험과 저장한 연락처를 이용해 새 거래처를 하루 안에 선택한 사례
- 가격을 계속 비교하지만 신선도·배송·품질·운반 부담 때문에 최저가만으로 결정하지 않은 사례
- 경쟁 관계인 주변 점주와 거래처·가격 정보를 거의 공유하지 않는 사례

## 아직 모르는 것

- 문제가 실제로 얼마나 자주 발생하는가?
- 탐색 시간과 손해 금액이 제품을 사용할 만큼 큰가?
- 가장 어려운 범주는 식자재, 설비, 폐기물, 인테리어 중 무엇인가?
- 점주가 경쟁 업체에도 가격과 후기를 공개할 수 있는가?
- 지도 형태가 문제 해결에 필요한가?

## 문제 정의 원칙

“자영업자를 위한 종합 플랫폼이 필요하다”는 문제 정의가 아닙니다. 반복되는 실제 사건과 비용이 확인된 한 가지 문제부터 선택합니다.
