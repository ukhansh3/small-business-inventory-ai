# 해결책 후보와 검증 질문

아래 기능은 확정 범위가 아니라 인터뷰 결과에 따라 선택하거나 폐기할 후보입니다.

## 1. 자영업자용 중고 집기 거래

- 가설: 일반 중고거래 서비스에서는 업소용 장비의 상태, 용량, 설치 조건을 비교하기 어렵다.
- 확인할 행동: 최근 업소용 장비를 사고판 경로, 탐색 기간, 운송·설치 비용, 사기·하자 경험

## 2. 도·소매 가격 비교

- 가설: 초보 점주는 품목별 적정 단가를 몰라 반복적으로 검색하거나 지인에게 묻는다.
- 확인할 행동: 실제 비교 횟수, 비교 업체 수, 가격 차이, 배송 조건 때문에 최저가를 포기한 경험

## 3. 외부업체 가격과 후기

- 대상: 폐기물·폐유, 수리, 청소, 인테리어, 간판 등
- 가설: 표준 가격이 없어 같은 지역·서비스에서도 견적 차이가 크다.
- 확인할 행동: 최근 견적, 추가 비용, 재작업, 주변 점주 추천, 업체 변경

## 4. 지도 기반 지역 정보

- 가설: 가격과 후기만큼 거리, 배송권역, 긴급 방문 가능 여부가 중요하다.
- 확인할 행동: 가까운 업체를 선택한 이유, 이동·배송 시간, 검색 시 실제로 사용한 지도

## 첫 기능 선택 기준

- 최근 6개월 내 반복 발생한 사건이 있는가?
- 사용자가 이미 시간이나 돈을 쓰고 있는가?
- 팀이 4개월 안에 필요한 데이터를 확보할 수 있는가?
- 정보 제공자가 공유할 동기가 있는가?
- 거래나 가격의 신뢰성을 검증할 최소 장치를 만들 수 있는가?
