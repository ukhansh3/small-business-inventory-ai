# 해결책 후보와 검증 질문

아래 기능은 확정 범위가 아니라 인터뷰 결과에 따라 선택하거나 폐기할 후보입니다.

## 1. 도·소매 가격 기준

- 가설: 익숙하지 않은 품목은 적정 단가를 판단할 기준이 부족하다.
- 확인된 신호: 가격을 우선 비교한 사례와 지인에게 알게 된 구매 채널이 있었음
- 남은 위험: 품질, 배송, 계약 조건이 달라 단순 가격표가 오히려 잘못된 비교를 만들 수 있음

## 2. 거래처·외부업체 탐색

- 대상: 식자재, 폐유·폐기물, 수리, 청소, 인테리어, 간판 등
- 가설: 낯선 범주의 업체를 찾을 때 검색과 비교 비용이 발생한다.
- 확인된 신호: 수리업체 탐색, 폐유업체 가격 차이, 새 식자재 거래처 탐색 사례가 있었음
- 남은 위험: 사건 발생 빈도가 낮고 기존 연락처나 영업사원만으로 빠르게 해결할 수 있음

## 3. 조건을 포함한 업체 정보

- 가설: 가격 외에도 배송 속도, 배송 가능 지역, 최소 주문량, 품질, 긴급 대응 여부가 선택에 중요하다.
- 확인된 신호: 더 비싸도 빠른 배송과 무거운 물품 운반 때문에 기존 거래처를 유지한 사례가 있었음
- 남은 위험: 조건이 자주 바뀌면 정보를 지속해서 최신 상태로 유지하기 어려움

## 근거가 아직 부족한 기능

- 자영업자 전용 중고 집기 거래: 인터뷰에서 최근 거래 사건을 확인하지 못함
- 지도 기반 탐색: 거리와 배송은 중요했지만 지도를 실제로 사용한 행동은 확인되지 않음
- 점주 공개 커뮤니티: 경쟁 업종끼리 거래처와 가격을 공유하지 않는다는 반대 근거가 있음
- 종합 플랫폼: 한 번에 여러 기능이 필요하다는 근거가 없음

## 첫 기능 선택 기준

- 최근 6개월 내 구체적인 사건이 여러 명에게서 나타났는가?
- 사용자가 이미 시간이나 돈을 쓰고 있는가?
- 팀이 4개월 안에 필요한 데이터를 확보할 수 있는가?
- 정보 제공자가 공유할 동기가 있는가?
- 거래나 가격의 신뢰성을 검증할 최소 장치를 만들 수 있는가?
