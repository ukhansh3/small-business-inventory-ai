# 현재 범위와 보류 항목

## 지금 하는 것

- 완료한 11건의 인터뷰 순서와 질문 변경 시점 정리
- 확인 가능한 녹음·전사 내용을 공통 기준으로 코딩
- 문제 빈도, 탐색 시간, 비교 수, 손해 금액의 실제 근거 확인
- 기존 경험, 연락처와 지인 네트워크가 판단에 미친 영향 확인
- 첫 번째 사용자 집단과 문제 범주 좁히기

## 아직 하지 않는 것

- 플랫폼 전체 기능 확정
- AI 기능을 넣기 위한 기능 설계
- 지도, 결제, 채팅, 중고거래를 한 번에 구현
- 인터뷰 근거가 없는 수익 모델 확정

## 보류한 방향

- 식당 간 공동구매
- 자동 식자재 발주량 예측
- 여러 배달 플랫폼의 품절 동기화
- 무인매장 CCTV 배회 알림

보류는 영구 폐기가 아닙니다. 새로운 사용자 증거가 생기면 별도의 ADR을 작성한 뒤 재검토합니다.
