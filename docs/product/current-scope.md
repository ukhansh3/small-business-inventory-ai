## P0 — 유지할 현재 MVP

- Supabase 이메일 인증과 세션
- 승인된 공급업체 목록·지도·상세 검색
- 업체 품목·규격·가격·세금·최소 주문·배송·확인일 표시
- 업체 소유자의 초안·수정본·사진 제출
- 운영자의 승인·보완 요청·숨김
- 승인본을 유지하는 revision 검토
- 공공업체 원문과 가상 가격을 분리한 `mvp_demo` 화면

P0는 수요 검증 완료 목록이 아니라 이미 구현된 MVP 검증 범위입니다.

## P1 — 근거·계약 승인 후

- 근거 연결 AI 자연어 검색
- 동일 규격 업체 비교표와 총비용 계산
- 즐겨찾기와 변경 알림
- 구매처 질문·가격 제보·거래 경험 커뮤니티

## 현재 비범위

- 주문·결제·배송 추적
- 점주 간 채팅·DM
- 실시간 재고·자동 발주
- 전국 최저가 보장
- 계정 생성만으로 사업자·업체 실재 인증
- 공공업체 시연 가격을 실제 견적으로 사용하는 기능

## 보류한 과거 방향

- 식당 간 공동구매
- 여러 배달 플랫폼 품절 동기화
- 무인점포 이상 탐지
- 자동 식자재 발주량 예측

## 검증 우선순위

1. I07·I08·I11 구조화와 기존 H1 판정 기준 적용
2. 비교 가능한 공급업체 Offer 데이터 확보 스파이크
3. 사장→운영자→지도 공개 전체 흐름 실기기 검증
4. 지도·목록에서 실제 후보 선택 행동 테스트
5. AI·커뮤니티 P1 유지 여부 결정

## 범위 변경 규칙

- P0 변경은 새 ADR과 SPEC·contract·수용 기준 수정이 필요합니다.
- 기능 구현과 사용자 문제 검증을 같은 상태로 기록하지 않습니다.
- 이미 적용된 migration을 고치지 않고 새 migration으로 변경합니다.
- 가격·업체 출처와 시연 경고를 약화하는 변경은 허용하지 않습니다.
