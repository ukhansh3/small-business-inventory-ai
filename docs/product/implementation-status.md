# 앱 기능 구현 현황

기준일: 2026-11-04 / 확인 브랜치: `민균`

이 문서는 현재 코드와 저장된 검증 기록을 정리한다. 구현 여부는 사용자 수요가 검증됐다는 뜻이 아니다. 미구현 항목도 모두 출시 필수 요구사항으로 확정한 것은 아니다. 제품의 문제 가설은 [문제 정의](problem-statement.md), 업체 직접 등록·검토 방향은 ADR-006·008을 따른다.

## 상태를 읽는 법

- **구현·실연결 검증**: 코드가 있고 실제 Supabase 또는 지도와 연결한 기록이 있다. 검증한 범위를 함께 적는다.
- **코드 구현·추가 검증 필요**: 화면·API·DB 코드가 있지만 실제 서비스 전체 흐름 검증이 남아 있다.
- **샘플 화면**: 예시 데이터로만 동작한다. 실제 서비스 기능으로 계산하지 않는다.
- **미구현 / 미결정**: 기능이 없거나 정책·범위를 결정해야 한다.

실연결 검증은 2026-10-29 기록 기준이며, 오늘 서버가 가동 중이라는 의미는 아니다.

## 구현된 기능

| 기능 | 상태 | 현재 범위와 한계 |
|---|---|---|
| Android·iOS 모바일 앱 구조 | 구현·실행 검증 | React Native·Expo 기반 네이티브 화면과 탭. 양쪽 실행 기록이 있으나 모든 기종·OS 호환 검증은 아니다. |
| 카카오 지도 | 구현·실연결 검증 | 지도만 HTTPS 지도 전용 페이지를 WebView로 표시. 지도에 DB 업체 좌표 전달. |
| 이메일 회원가입·로그인·로그아웃 | 코드 구현, 로그인 실연결 검증 | Supabase Auth 사용. 테스트 계정 iPhone 로그인 확인. 신규 가입 메일 확인 등 전체 계정 수명주기 검증은 남아 있다. |
| 로그인 세션 보관 | 코드 구현·추가 검증 필요 | 기기 암호화 저장소 사용, 세션 갱신·로그아웃 코드와 저장소 테스트가 있다. |
| 가까운 승인 업체 검색 | 구현·실연결 검증 | 로그인 사용자에게 지도 중심·반경 기준으로 현재 승인본만 반환. 검색·카테고리·페이지 이동 코드가 있다. |
| 업체명·품목 검색 및 분류 필터 | 구현·실연결 검증 | iPhone에서 양파 검색 1건, 포장재 필터 1건 확인. |
| 업체 목록·지도 핀·상세 | 구현·실연결 검증 | 실제 DB의 가상 업체 3곳 조회. 상세 가격·배송비·세금·확인일 확인. |
| 현재 위치로 이동 | 코드 구현·추가 검증 필요 | 위치 권한 요청·거부 처리. 실제 기기의 위치 정확도와 권한 변경 검증 필요. |
| 업체 초안 등록·수정·저장 | 코드 구현·추가 검증 필요 | 사장 계정 소유 업체만 관리. 업체명·주소·연락처·영업시간·거래 조건 입력. 실제 앱 입력부터 저장까지 전체 검증 필요. |
| 업체별 여러 품목·가격 | 코드 구현, DB 조회 실연결 검증 | 품명·규격·수량·단위·가격·부가세·최소 주문·확인일·배송비 저장 구조. 가상 품목을 실제 DB에서 읽은 기록이 있다. |
| 업체 사진 | 코드 구현·추가 검증 필요 | 기기 사진 선택, JPEG/PNG/WebP 3MB 이하, 제출본당 최대 10개. 비공개 Storage와 권한 검사 API. 실제 기기 업로드 전체 검증 필요. |
| 주소 좌표 확인 | 코드 구현·추가 검증 필요 | 서버 카카오 REST 지오코딩, 모호한 주소는 제출 거절. 이번 가상 업체 좌표는 임의 배치했으므로 주소 검증 증거가 아니다. |
| 운영자 검토 요청·취소·보완 재제출 | 코드 구현·추가 검증 필요 | 작성 중 → 검토 대기 → 승인/보완 상태 관리. 실제 사장·운영자 앱 화면을 잇는 전체 검증 필요. |
| 운영자 승인·보완 요청 | 코드 구현, DB 함수 실행 검증 | 운영자 전용 화면·API, 자기 업체 승인 차단. 가상 업체는 DB 함수로 승인했고 운영자 앱 화면 승인까지 검증한 것은 아니다. |
| 승인 후 수정본 재검토 | 코드 구현, DB 함수 실행 검증 | 기존 승인본을 유지하며 새 수정본을 검토. 가상 업체 카테고리를 수정본으로 재승인한 기록이 있다. |
| 업체 숨김·다시 공개 | 서버·DB만 구현 | 권한 검사 API와 DB 함수가 있다. 모바일에서 조작하는 버튼은 아직 없다. |
| 접근 권한·사진 비공개 처리 | 코드 구현, 실제 DB 설정 확인 | RLS·소유권·검토자 권한·승인본 불변·내부 메모 분리. 자동 테스트와 실제 DB 권한 설정 확인 기록. 전체 보안 검토 완료를 뜻하지 않는다. |
| 오류·샘플 모드 분리 | 코드 구현·추가 검증 필요 | 설정이 없으면 샘플 표시. 실제 DB 오류를 샘플 업체로 대체하지 않는다. |

## 아직 실제 기능으로 구현되지 않은 부분

| 항목 | 현재 상태 | 남은 내용 |
|---|---|---|
| AI 도우미 | 샘플 화면 | 고정 샘플 자료의 키워드 검색만 한다. 실제 AI 모델·자연어 응답·실제 DB 검색 연결 없음. |
| AI 음성 대화 | 미구현 | 음성 인식·음성 응답·마이크 흐름 없음. 도입 범위 미확정. |
| 사장님 커뮤니티 | 샘플 화면 | 고정 예시 글만 표시. 게시글 작성·수정·삭제·댓글·신고·운영 처리 DB/API 없음. |
| 업체 저장·즐겨찾기 | 미구현 | 계정별 저장 목록 없음. |
| 업체 비교표·가격 정렬 | 미구현 | 개별 가격 조회는 가능하지만 복수 업체 비교표·동일 규격 환산·총비용 정렬 없음. |
| 채팅·DM, 주문·결제·배송 추적 | 미구현 | 실제 거래 처리 기능 없음. 구현 범위 결정 필요. |
| 푸시 알림 | 미구현 | 승인 결과·가격 변경 등을 알리는 기기 알림 없음. |
| 사업자·업체 소유 증빙 | 미결정·미구현 | 현재 계정 소유권 검사는 실제 사업자 인증과 다르다. 증빙·심사 정책 필요. |
| 비밀번호 재설정·회원 탈퇴 | 미구현 | 앱 화면 및 계정·관련 데이터 처리 정책 필요. |
| 비로그인 업체 공개 범위 | 미결정 | 현재 실제 업체 검색은 로그인 필요. |
| 상시 운영자 계정·운영 절차 | 준비 필요 | 가상 검증용 검토자에게 지속 권한을 주지 않았다. 실제 담당자 지정·보완 처리·운영 절차 필요. |

## 서버·DB·배포 상태

| 구분 | 현재 상태 |
|---|---|
| DB | 실제 Supabase에 업체 등록용 테이블·함수·RLS·비공개 사진 버킷 적용 완료. 실제 업체가 아닌 `[가상테스트]` 업체 3곳을 등록·승인했다. |
| API 서버 | `apps/cheonhajangsa`에 구현. 로컬 컴퓨터의 4340 포트 서버로 실제 DB 검색을 검증했다. 상시 운영 가동 여부와는 별개다. |
| 지도 페이지 | `https://cheonhajangsa.vercel.app/mobile-map`을 이용한 지도 연결 기록이 있다. 지도 페이지 배포만으로 새 업체 API 전체가 배포된 것은 아니다. |
| 서버 운영 방침 | 사용자 선택은 본인 컴퓨터에서 서버 실행. 별도 클라우드 API 서버로 이전을 전제로 하지 않는다. |
| 팀원·휴대폰 연결 | 같은 Wi-Fi에서는 서버를 LAN 접속 가능하게 실행하고 앱 API 주소에 서버 컴퓨터 IP를 지정해야 한다. 기존 시뮬레이터의 `127.0.0.1:4340` 설정은 다른 팀원 기기에서 그대로 사용할 수 없다. LAN 공동 접속 검증은 아직 별도다. |
| 다른 네트워크 접속 | 외부 접속 주소·방식 미구성. 필요하면 범위를 정해 마련한다. |
| Android 설치 파일·iOS 배포 | Expo/EAS 빌드 설정은 있음. 현재 DB 연결 버전의 정식 서명·배포 검증과 스토어 출시는 미완료. 이전 WebView APK를 현재 네이티브 앱 완성본으로 보지 않는다. |
| 환경 변수 | 실제 키는 Git에 없음. 팀원은 예시 파일을 복사해 공개 설정을 입력하고, 서버 컴퓨터에만 서버 전용 키를 둔다. |

## 다음 확인 순서

1. 본인 컴퓨터 API 서버를 켜고 같은 Wi-Fi의 팀원 기기에서 실제 DB 검색 확인.
2. 실제 사장 계정과 별도 운영자 계정으로 앱에서 등록 → 사진 업로드 → 제출 → 보완 → 승인 → 지도 공개까지 검증.
3. 회원가입 메일·비밀번호 재설정·탈퇴, 사업자 확인·운영자 처리 정책의 출시 필요 범위 결정.
4. 현재 DB 연결 버전의 Android·iOS 설치·배포 검증, 지원 기종 확인.
5. AI·커뮤니티·비교 기능은 사용자 검증과 우선순위 결정 후 진행.
