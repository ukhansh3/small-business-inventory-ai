# 문제 정의 v0.2

상태: 인터뷰 복구 후 판정할 가설 / 팀 검토안
기준: `I01~I12` 수행, 구조화 9건

## 한 문장 문제

익숙하지 않은 품목이나 공급업체를 새로 선택해야 하는 소규모 외식업 점주는 비교 가능한 가격·품질·배송 조건 정보가 흩어져 있어 검색, 영업사원, 저장 연락처와 지인에게 개별적으로 확인하며, 이 과정에서 탐색 시간과 잘못된 선택 비용을 부담할 수 있다.

이 문장은 검증 완료 결론이 아니라 반증 가능한 문제 가설입니다.

## 대상 사용자

- 품목·공급업체 선택을 직접 담당하는 소규모 외식업 점주
- 최근 낯선 품목·설비·외부업체를 새로 판단한 사건이 있는 사람
- 해당 범주의 가격·품질 기준이나 연락처가 부족한 사람

## 비교·비대상 사용자

- 거래처가 안정적으로 고정돼 최근 새 선택 사건이 없는 점주 (`I04-E01`, `I12-E02`)
- 경험·저장 연락처로 같은 판단을 빠르게 끝내는 점주 (`I09-E01`)
- 본사 지정 구매만 가능해 공급업체 선택권이 없는 품목의 점주 (`I12` 일부 품목)

`개업 3년 이하`만으로 대상을 나누지 않습니다. 인터뷰에서는 업력보다 해당 품목 경험과 연락처가 행동 차이를 더 잘 설명할 가능성이 나타났습니다.

## 대가

현재 확인된 대가는 다음과 같지만 금액화가 부족합니다.

- 여러 업체·구매처를 확인하는 시간 (`I02-E02`, `I12-E01`)
- 배송 누락 후 비싼 긴급 구매 또는 판매 중단 (`I09-E02`, 금액 미확인)
- 잘못된 대체 구매 후 원래 공급품으로 복귀 (`I12-E03`)
- 직접 구매·운반의 신체 부담 (`I03-E02`, `I10-E03`)

다음 인터뷰에서는 연락·방문 수, 소요 시간, 견적 차이, 손실액을 질문해 `미확인`을 줄입니다.

## 반대 근거

- 기존 거래처를 편의성 때문에 유지하며 가격 차이를 크게 느끼지 않은 사례 (`I04-E01`)
- 경험과 연락처로 하루 안에 선택한 사례 (`I09-E01`)
- 거래처가 정착된 뒤 같은 탐색이 드물어진 사례 (`I12-E02`)
- 주변 경쟁 점주와 거래처·가격을 공유하지 않은 사례 (`I09-E03`, `I10-E02`)

따라서 모든 자영업자의 상시 문제 또는 공개 커뮤니티 문제로 일반화하지 않습니다.

## 반증 조건

수정 대본에 이미 적어 둔 기준을 결과에 맞춰 바꾸지 않습니다.

- `I08~I12` 다섯 건에서 H1-a 빈도와 H1-b 비용이 모두 3건 이상이면 문제 가설 유지
- H1-b가 1건 이하이면 핵심 문제 폐기 또는 재정의
- H1-c 실제 공유 행동이 0건이면 공개 공유 기반 해결책 폐기

현재 I08·I11이 구조화되지 않아 최종 판정은 보류합니다.

## 행동 기반 성공 정의

향후 사용자 테스트에서 다음 행동을 측정합니다.

- 사용자가 가격만이 아니라 규격·품질 대리정보·배송·확인일을 보고 후보를 설명함
- 기존 방식 대비 연락 업체 수 또는 소요 시간이 줄어듦
- 데이터가 부족할 때 임의 선택하지 않고 재확인 필요를 구분함
- 실제로 업체 상세를 확인하거나 문의 행동으로 이어짐

호감도와 “있으면 좋겠다”는 답만으로 성공 판정하지 않습니다. 표본 수와 합격선은 테스트 전에 별도 등록합니다.

## 해결책과의 경계

지도, AI, 커뮤니티, 업체 등록은 위 문제를 시험하기 위한 제품 가설입니다. 인터뷰 관찰 사실이 아니며 구현했다는 이유로 문제 가설의 근거가 되지 않습니다.
