# 천하장사 시연 시나리오 (5탭 연결, QA용)

> 아래 업체·금액은 **가상 예시**. 공개 실업체·실거래 가격이라고 주장하지 않는다. 본 시나리오는 구현 검증 체크리스트이지 실행 결과가 아니다.

## 시나리오 1 — 지도에서 품목 탐색
1. 앱을 연다. **로그인 창 없이** 지도 홈, 지도 위치 안내, 하단 접힌 `주변 업체 N곳` 요약바가 보인다.
2. `양파`를 검색하고 키보드 검색 액션을 누른다. 단일 품목 일치 핀에는 `양파 10kg · 18,000원`, 다중 일치에는 `일치 품목 2개`가 표시된다.
3. 클러스터를 탭하면 확대만 되고 API 재검색이 발생하지 않는다. 확대 후 `이 지역 검색` 버튼이 나타난다.
4. 버튼을 눌러 **현재 보이는 영역**을 재검색한다. 지도 전체 업체가 클러스터 집계에 포함되고 하단 목록은 20개씩 나뉜다.
5. 핀을 누르면 하단 업체 카드가 뜬다. 업체 상세에서 가격·규격·부가세·배송·확인일을 검토하고 `저장`을 누른다.
6. 하단 목록 펼침 → 다른 업체 선택 → 카메라 이동 + 선택 업체 카드로 접힘.

## 시나리오 2 — AI 추천과 지도 연동
1. AI 도우미 탭에서 `근처에 양파 10kg 배송되는 곳 찾아줘`를 보낸다.
2. AI는 마지막 적용 지도 영역을 기준으로 품목/단위/배송 의도를 구조화하고 서버 업체 DB를 조회한다.
3. 실제 LLM이 설명을 생성하되 카드의 업체·가격·배송 조건은 **서버 검증 값만** 나온다. 비교 불가능하면 가격 순위를 매기지 않는다.
4. `지도에서 보기`로 지도 탭의 업체 선택 카드에 도착한다. 지도 이동만으로 새 지역 검색을 자동 호출하지 않는다.
5. 다시 AI 탭으로 와도 같은 시연 세션 동안 대화가 유지된다.

## 시나리오 3 — 커뮤니티 참여
1. 커뮤니티에서 `구매처 질문` 필터를 누르고 글을 읽는다.
2. 주황 작성 버튼으로 제목·본문·사진을 넣어 질문글을 작성한다. 작성자 닉네임은 로그인 UI 없이 자동 제공된다.
3. 댓글, 좋아요, 게시글 저장이 실제로 동작한다. 본인 글·댓글만 수정/삭제 가능하다.
4. 가격 제보는 참고 콘텐츠로만 표시되고 실제 업체 공식 가격으로 들어가지 않는다.
5. 시연 관리자 모드(보안 검증된 진입 방식 필요)에서 신고를 처리해 숨긴 글이 피드·상세·저장에서 차단되는지 확인한다.

## 시나리오 4 — 저장과 UI 전용 내 정보
1. 저장 탭 `전체/업체/게시글`을 전환하고 각 상세를 열어본다.
2. 북마크를 다시 탭해 저장 해제하면 원래 화면과 저장 목록에서 모두 해제된다.
3. 내 정보는 `내 업체` UI 미리보기만 보여주고 `준비 중` 상태를 표시한다. 서버에 업체 등록/승인 쓰기를 하지 않는다.

## 시나리오 5 — 자동 초기화/보안
1. 세션 A에서 글, 댓글, 저장, AI 대화를 만든다. 세션 B에서는 A의 데이터가 보이거나 수정되지 않는다.
2. **새 시연 시작**을 선택하면 A만 새 세션으로 초기화된다. B와 실제 공개 업체는 유지된다.
3. 로그인 UI 없이 다시 지도를 볼 수 있다. 모델·지도·DB 장애 화면은 검색 0건과 구분된다.

## 시연 전 필수 데이터/설정
- 시연을 위해 준비된 **가상 업체/품목/가격**에 출처 표기, 실제 공개업체는 읽기전용 사본 사용 시 마지막 동기화 시각 노출.
- 실제 LLM 서버 키 및 모델 호출 제한, 이미지 저장 정책, Android 지도 허용 도메인/키 환경 확인.
- 시연 데이터 reset이 동작한다는 DB/Storage 테스트 증빙. **이 시나리오만으로는 기능 동작을 보증하지 않음.**
