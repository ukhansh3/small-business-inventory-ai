# 5탭 화면 검토 가이드 (실제 목업과 대조)

> 사용자 제공 세 장의 모바일 목업을 디자인 기준으로 하고, 여기의 ASCII 배치는 기능 검토용. 실제 화면 픽셀/실행 스크린샷 아님.

## 1. 지도 탐색
```text
┌────────────────────────────┐
│ 천하장사       아주대 주변 │
│ [어떤 품목을 찾으세요?]   │
│ [식자재] [소모품] [배송 가능]│
├────────────────────────────┤
│                            │
│        지도 + 업체 핀      │
│           (24)             │
│       [이 지역 검색]       │
│                            │
├────────────────────────────┤
│ ──   주변 업체 N곳         │   ← 초기 PEEK
│  또는  선택 업체 + 가격    │   ← 핀 SELECTED_CARD
│  위로 밀면 20개씩 목록     │   ← EXPANDED_LIST
├────────────────────────────┤
│ 지도 AI 커뮤니티 저장 내 정보│
└────────────────────────────┘
```
## 2. AI 도우미
사용자 주황 말풍선/AI 응답/출처별 비교 카드/`지도에서 보기`/하단 채팅 입력. 가짜 가격 금지.

## 3. 사장님 커뮤니티
카테고리 칩, 본문 카드/사진/댓글수·좋아요·저장, 우측 아래 주황 글쓰기 버튼, 글 상세·작성·신고.

## 4. 저장
`전체/업체/게시글` 필터, 최근 저장순. 원본이 사라졌다면 예전 글 본문·가격 그대로 노출 금지.

## 5. 내 정보
목업과 동일한 5탭 중 마지막. 계정 로그인 유도 없이 프로필/업체관리 **UI 미리보기**. 등록/수정/승인 처리 버튼은 `준비 중`.

## 코덱스 첫 UI PR 검토 체크리스트
- 제목/본문 검정 계열(`colors.ink` 남색 그대로 방치 X), 주황 강조/흰 배경.
- 기존 목업과 컴포넌트 순서·핀/시트/탭/카드가 일치하는지 실제 Android 스크린샷으로 비교.
- 핸드폰 화면 크기·키보드·제스처·접근성(탭/시트 겹침)을 검증.
- fake 데이터는 시연임을 명시. 실제 동작하지 않는 기능은 완료/저장 성공 문구 금지.
