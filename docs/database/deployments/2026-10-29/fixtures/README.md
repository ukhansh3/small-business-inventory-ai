# 아주대 주변 가상 업체 검색 검증

2026-10-29 사용자의 명시적 요청으로 실제 Supabase에 가상 업체 3곳을 추가했다. 실제 업체·가격·주소 정보가 아니며 거래할 수 없다. 모두 이름에 `[가상테스트]`를 붙였다.

| 업체 | 품목 | 테스트 가격 |
|---|---|---:|
| 아주 채소상회 | 양파 | 18,000원 |
| 원천 포장마켓 | 포장용기 | 24,000원 |
| 아주 쌀도매 | 쌀 | 52,000원 |

각 배송비는 가상 3,000원이다. 좌표는 아주대 중심에서 약 236~323m에 임의 배치했다. 실제 주소를 카카오로 검증한 업체가 아니다.

별도 가상 사장·검토자 Auth 계정으로 초안 저장 → 좌표 지정 → 검토 요청 → 승인 함수를 사용했다. 검토자 권한은 하나의 트랜잭션 안에서만 사용하고 커밋 전에 제거했으므로 지속적인 운영자 권한은 부여하지 않았다. 기존 업체나 사용자는 변경하지 않았다.

실제 사용자 토큰으로 로컬 API(127.0.0.1:4340)를 호출하여 전체 검색 3건, `양파` 검색 1건, `포장용기` 검색 1건과 `data_kind: live`, HTTP 200을 확인했다. 모바일에는 공개 Supabase 설정과 로컬 API 주소만 넣었다. 비밀키와 테스트 계정 비밀번호는 Git에 포함하지 않는다.

## iPhone 시뮬레이터에서 확인한 내용

- 테스트 계정으로 실제 Supabase Auth 로그인 성공.
- 지도 탭에 현재 공개 업체 3곳과 카카오 지도 핀 3개 표시.
- `양파` 검색 → 아주 채소상회 1곳, 18,000원.
- 상세 화면에 배송비 3,000원, 부가세 포함, 업체 확인일 표시.
- 앱 분류와 맞도록 새 수정본을 재승인해 식자재 2곳·포장재 1곳으로 정리. 포장재 필터 → 원천 포장마켓 1곳, 24,000원.
- 증빙: ios-live-map.png, ios-live-detail.png, ios-live-category.png.

현재 검증은 로컬 API 서버와 Expo 개발 서버가 실행 중인 시뮬레이터 기준이다. Vercel 운영 서버에 이 브랜치 API를 배포했다는 의미는 아니다. Android 에뮬레이터에도 Expo Go를 설치했으나 이번 실제 로그인·검색 UI 검증은 iPhone에서 수행했다.
