# 1. 프로젝트 시작과 도메인 탐색

## 출발점

팀은 세 명으로 구성되었고, 초기 목표는 2주 안에 인터뷰 가능한 실사용자 10명을 확보하는 것이었습니다. 기술적으로 흥미로운 아이디어보다 실제 사용자에게 접근할 수 있는지를 먼저 확인하기로 했습니다.

초기 도메인 후보는 다음과 같았습니다.

- 대학생 팀플 관리: 역할 분담, 회의 후속 조치, 일정 지연
- 취업 준비생 면접 코치: 연습과 구체적인 피드백 부족
- 자취생 식재료·식비 관리: 식재료와 비용 낭비

## 접근성 기준

- 2주 안에 사용자 10명을 직접 또는 화상으로 만날 수 있는가?
- 누구에게 어떤 경로로 연락할지 구체적인가?
- 응답이 없을 때 다시 접근할 사용자 풀이 있는가?
- 의견이 아니라 실제 경험과 구체적인 사례를 들을 수 있는가?

## 이 단계의 의미

최종적으로 선택한 자영업 도메인은 최초 세 후보에 없었습니다. 이후 브레인스토밍과 사용자 접근 가능성을 검토하면서 학교 인근 상권의 점주를 직접 방문할 수 있다는 점이 중요한 선택 근거가 되었습니다.
