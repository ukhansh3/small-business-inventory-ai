# 3. 자영업 도메인의 초기 문제 가설

자영업 도메인을 선택한 뒤 재고, 알바, 피크타임, 개폐업, 매물 정보 등 여러 문제를 모았습니다.

## 관찰하거나 검토한 문제

- 재고가 없어도 배달 주문이 결제되어 환불과 품절 처리가 어려운 문제
- 여러 배달 플랫폼에서 품절 상태를 각각 처리해야 할 가능성
- 피크타임에 조리 외 주문·전화·품절 정보 처리가 몰리는 문제
- 냉장고 실물 재고와 발주 판단이 어긋날 가능성
- 알바 당일 취소와 신규 알바 인수인계
- 매장 양도 시 매출은 보여도 순이익은 알기 어려운 문제
- 초보 사장님의 정보 부족과 디지털 활용 격차

## 당시 가설

### 가설 A. 품절 상태가 플랫폼마다 따로 논다

사장이 배달 플랫폼별로 품절을 각각 반영해야 하고, 피크타임에는 처리가 늦어져 환불·취소·리뷰 손실이 발생할 수 있다는 가설입니다.

### 가설 B. 피크타임 병목이 조리가 아니라 정보 처리다

추가 인력이 조리가 아니라 주문 접수, 품절 처리, 전화 응대에 쓰인다면 소프트웨어가 인건비를 줄일 가능성이 있다는 가설입니다.

### 가설 C. 냉장고 실물과 장부가 어긋난다

사장이 실사보다 감으로 발주해 폐기와 품절이 동시에 발생할 수 있다는 가설입니다.

### 가설 D. 매물 순이익이 구조적으로 은폐된다

예비 창업자가 점포 인수 전에 실제 순이익을 확인하기 어렵고, 인수 후 예상과 다른 상황을 겪을 수 있다는 가설입니다.

## 당시 해결책 후보

1. 여러 배달 플랫폼의 품절 상태 동기화
2. 마감 실사 없는 발주 보조
3. 매물 순이익 검증

이 가설들은 당시 인터뷰 증거가 충분하지 않았고, 이후 1차 인터뷰에서도 A·B·D는 검증되지 않았으며 C는 예상과 다른 결과가 나왔습니다.
