# 2. 브레인스토밍과 후보 선별

## 1차 아이디어 발산

초기에는 영양제 추천, 냉장고 털이, 반려견 배변 훈련, 주식 주문, 반려견 외출 불안, 꿈 기록, 한적한 데이트 코스, 중고거래 상태 리포트, 스팸메일 검토 등 다양한 아이디어를 제한 없이 제시했습니다.

## 2차 브레인스토밍

팀원들이 공통으로 관심을 보인 냉장고·식재료 문제를 포함해 공공장소 알람, 부모님 건강 상태 확인 등을 검토했습니다. 이때는 문제보다 해결책이 먼저 나온 아이디어가 많았습니다.

## 3차 브레인스토밍

문제, 고객, 수익 가능성, 데이터, 4개월 MVP 범위를 더 구체적으로 작성했습니다. 주요 원안은 다음과 같습니다.

- 스트리밍 경기 재개 알림
- 야간 택시 입찰
- 오케스트라 자동 악보 넘김
- 수면용 음향기기
- 상황 맞춤형 보행 내비게이션

원안을 재구성하고 여러 차례 검토한 뒤 다음 네 후보를 남겼습니다.

1. 악기 레슨생 연습 녹음 자동 피드백
2. 초소형 무인매장 야간 배회 알림
3. 소형 외식업장 식자재 발주량 예측
4. 반려견 짖음·하울링 오디오 이벤트 리포트

## 자영업 도메인으로 이어진 이유

후보 중 무인매장과 외식업장 문제가 자영업자와 연결됐고, 학교 주변에서 점주를 직접 만날 수 있었습니다. 별도의 데이터 제휴보다 사용자 인터뷰를 먼저 시작할 수 있다는 점 때문에 자영업 문제 탐색이 구체화되었습니다.

## 중간에 검토한 CCTV 후보

별도 주제 후보 페이지에서는 카메라 1~2대를 쓰는 초소형 무인매장의 야간 배회 알림을 구체화했습니다. 기존 CCTV에서 장시간 체류·반복 배회만 골라 알리는 B2B 서비스였지만, 실제 점주의 CCTV 열람 행동과 사고 경험을 먼저 검증해야 했습니다. 이후 팀의 사용자 접근과 인터뷰는 외식업 점주 쪽으로 이동했습니다.
