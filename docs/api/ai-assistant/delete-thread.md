# API-AI-DELETE-THREAD — DELETE /api/v1/ai/threads/{threadId} (제안)

- **구현 상태:** 미존재. 특정 대화 삭제는 **기술 제안**이며 사용자에게 별도 대화별 삭제 UI가 승인된 것은 아니다.
- 입력: 서버 발급 `threadId` + 세션 권한. 응답 제안: `204 No Content`.
- 해당 시연 세션 소유의 메시지/추천 참조만 삭제. 실제 업체·승인품목·타 시연 세션 데이터/운영자료는 삭제 금지.
- **새 시연 시작으로 모든 대화 자동 초기화**하는 실제 호출 흐름/트리거는 향후 `demo-session` 통합 명세의 책임. 이 DELETE 엔드포인트의 존재만으로 AI-10 완료가 되지 않는다.
- 테스트: 정상 삭제, 다른 세션 스코프 차단, 중복 삭제 멱등성 정책 선택, 운영 데이터 불변.
