# API-AI-COMMON — AI 도우미 API 계약 제안

> **상태: 구현 제안 / 아직 GitHub main에 존재하지 않는 엔드포인트.** AI-01~10은 사용자 승인된 **제품 기능**이며, 아래 경로·JSON·DB 구조의 별도 승인은 아직 아니다.

## 제안 인터페이스
- `POST /api/v1/ai/messages` — 사용자 메시지 접수, 구조화된 근거 기반 답변+추천 카드.
- `GET /api/v1/ai/threads/{threadId}/messages` — 시연 세션 메시지 재조회.
- `DELETE /api/v1/ai/threads/{threadId}` — 해당 대화 제거. **새 시연 시작**에 따른 전체 세션 리셋은 별도 데모 세션 API 책임.

## 접근 제약
- UI에 로그인 화면은 두지 않으나, 서버 요청은 검증된 세션으로 범위를 격리. `auth.uid()` 또는 동등한 안전한 서버 발급 세션과 DB RLS를 거친다.
- `main`의 `endpoint()`는 Bearer Auth가 필수이며 익명 데모 진입이 아직 미지원. 이 공백을 해결하기 전에는 AI API 연결 완료를 주장하지 않는다.
- 모델 키, 백엔드 AI 제공자 토큰, DB 서비스 권한 키는 서버 전용. Expo 환경변수·WebView·API 응답에 넣지 않는다.
- 사용자 메시지·대화 기록·대상 업체 ID는 크기/형식 검증, 세션 간 IDOR 방지, 과다 요청 방지. 모델 출력은 검증 가능한 데이터/화면 카드 계약으로 제한.

## 공통 불변조건
- 추천 카드의 가격·품목·업체 ID는 검색·상세 공개 DTO의 검증된 필드를 재구성. 모델 임의 생성 금지.
- `data_kind`와 근거 레코드, `checked_on` (가능할 때)을 함께 제공; 시연자료가 실제 업체가 준 가격처럼 보이면 안 됨.
- 모델 장애/검색 장애/조건에 맞는 업체 0건을 서로 구분해 응답. 오류 응답은 기존 `error.code/message/requestId` 구조를 가급적 재사용.
- 지도 적용 영역의 사각형 bounds 필드명, 과대 영역/날짜경계/전국 조회 제한은 지도 API 최종 계약과 동기화한다.
- 서버가 모델을 호출하기 전에 공개 승인 자료만 가져오고 시스템 지시/도구 호출 허용 범위를 제한한다.
