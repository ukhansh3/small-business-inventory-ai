# DELETE /api/v1/saved/vendors/{vendorId} — 업체 저장 해제

**상태:** S-02/08 기반 제안 / 미구현.

## Request
`vendorId` UUID 경로값, 본문 없음. 저장한 시연 세션은 서버 인증값으로 판정.

## Response
`200 {"vendor_id":"<UUID>","is_saved":false}`.

## 권한·동작
- 본인의 시연 actor가 등록한 저장만 삭제한다. 미저장 항목에 반복 DELETE해도 성공하는 멱등 연산. 타 세션 저장은 변경 불가.
- 원본 업체·품목·타 시연 데이터 삭제 금지.
- 오류: 401 세션 만료, 422 ID 형식, 503 DB 장애. 존재 여부 노출을 피하도록 미저장·타인의 저장 상태는 모두 동일한 `is_saved=false` 처리.

## 테스트
중복 DELETE 200, 저장 후 해제 및 여러 화면 동기화, 타 세션 데이터 불변, 원본 업체 정보 불변.
