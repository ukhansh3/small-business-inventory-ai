# 공공 업체 MVP 시연 데이터

2026-11-04 / 민균 브랜치. 사용자 요청으로 실제 Supabase `mvp_public_vendors`에 공공 업체 8곳을 저장했다. 실제 서비스는 업체 사장 직접 등록을 유지하며 이번 데이터는 별도 시연 화면에서만 표시한다.

## 실제 정보

- 출처: [공공데이터포털 3079598](https://www.data.go.kr/data/3079598/fileData.do), 경기도 광주시 전문건설업 등록현황.
- 원문: `경기도_광주시_전문건설업현황_20260306.csv`, 총 693행, 기준일 2026-03-06.
- 이용허락: 공식 카탈로그에 ‘이용허락범위 제한 없음’ 표시. 2026-11-04 확인.
- 업체명·주소·업종·기준일을 원문 그대로 보관. 복수 업종 구분자도 유지.
- 주소 좌표는 기존 Kakao 주소 API에서 단일 결과로 확인. 수원이나 아주대로 이동시키지 않았다.
- 이번 자료의 지역은 경기도 광주시다. 수원·아주대 주변 목록을 확보했다는 의미는 아니다.
- 경기도 폐기물 원본 사이트는 접속 차단으로 이번 가져오기에 포함하지 않았다.

## DB와 조회

- migration: `supabase/migrations/202611040001_public_vendor_mvp.sql`. 실제 프로젝트 SQL Editor에서 적용했다. 같은 프로젝트에 다시 실행하지 않는다.
- 로그인 사용자만 읽기 가능. 앱·일반 계정은 삽입·수정 불가. 운영자 권한이나 업체 사장 소유권을 만들지 않았다.
- `GET /api/v1/mvp-vendors?query=실내&offset=0`: 기존 Bearer 인증을 사용한다. 이름·업종·시연 작업의 부분 문자열 검색과 페이지당 20건.
- 기존 `/vendors` 승인 업체 API와 기존 등록·승인 데이터는 변경하지 않는다.
- 앱: 지도 탭 → ‘공공 업체 MVP 시연 보기’. 지도 핀 선택·목록·원문 출처·기준일·가상 가격 표시. 카카오 지도 핀에는 가격을 보내지 않는다.
- 원문 CSV와 정확한 주소, 실제 키·계정은 Git에 포함하지 않는다. 원문 SHA256과 원문 행 식별 해시는 DB에 보존한다.

## 검증 결과

- 실제 Supabase에 8행 삽입 응답 확인. 모든 행의 업체 미확인·시연 플래그 확인.
- 서버 63개, 모바일 32개 테스트 통과. 양쪽 lint·typecheck 통과.
- Android·iOS 번들 생성 성공. 서버 Webpack 프로덕션 빌드 성공. Turbopack은 이 환경의 포트 생성 제한으로 실패하여 Webpack으로 검증.
- 새 화면의 시뮬레이터 UI 검증은 추가 실행하지 않았다.

- 실제 로컬 API 검증: 전체 8건, `실내` 3건, `가스` 3건 HTTP 200. 모든 행의 이름·업종·주소가 원문과 일치. 비로그인 API 401, 익명 RPC·일반 사용자 쓰기 거부 확인.
