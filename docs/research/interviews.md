# 인터뷰 프로토콜과 로그

총 12명의 자영업자를 연속적으로 인터뷰했습니다. `I01~I07` 이후 질문 초점을 바꿨으며 별도의 독립 표본으로 번호를 다시 시작하지 않았습니다.

[인터뷰 프로토콜과 사전 기준](../interviews/guides/revised-information-asymmetry-guide.md)을 참고합니다.

## 자료 상태

| 구분 | 건수 | ID | 의미 |
|---|---:|---|---|
| 인터뷰·음성 보관 | 12 | I01~I12 | 수행 사실 확인 |
| 구조화 요약 있음 | 12 | I01~I12 | 사건 요약을 분석에 사용 |
| 자동 전사 기반 신규 요약 | 3 | I07, I08, I11 | 정성 근거로 사용. 신규 수치와 직접 인용의 원음 대조 필요 |
| 일시 확인 완료 | 0 | - | 공개 로그에 인터뷰 일시가 없음 |
| 직접 인용 대조 완료 | 0 | - | 현재 로그는 요약이며 직접 인용 아님 |
| 수정 전 질문 G01 | 7 | I01~I07 | 재고·발주·공동구매를 넓게 탐색 |
| 수정 후 질문 G02 | 5 | I08~I12 | 업체 탐색·가격 판단·정보 교환을 질문 |

`일시 확인 완료 0건`, `직접 인용 대조 완료 0건`은 인터뷰가 없었다는 뜻이 아니라 공개 저장소의 현재 기록 수준을 뜻합니다. 원음·원본 메타데이터 대조 후에만 숫자를 올립니다.

## 판정 원칙

- 질문하지 않은 내용은 반대 근거가 아니라 `미확인`입니다.
- 요약 문장을 따옴표로 바꿔 직접 인용처럼 사용하지 않습니다.
- 사건이 있어도 업체 수·시간·금액이 없으면 수치 비용 판정에는 사용하지 않습니다.
- 문제를 겪지 않은 사례와 경험으로 빠르게 해결한 사례를 함께 보존합니다.
- G02 다섯 건에 기존 사전 기준을 적용한 결과는 [증거 행렬](../interviews/synthesis/current-evidence-matrix.md)에 기록했습니다.

관찰 기록과 핵심 Job Story는 확인 가능한 자료를 바탕으로 별도 정리합니다. 현재 증거 행렬은 인터뷰에서 보고된 과거 행동을 정리한 것입니다.

## 개인정보

공개 저장소에는 매장명, 성명, 개인 연락처, 정확한 매장 주소, 동의서 원본과 전체 전사본을 저장하지 않습니다. 직접 인용을 추가할 때 식별 가능한 업체명·지역·인물 관계를 익명화합니다.
