# 인터뷰 인덱스

총 11명의 자영업자를 연속적으로 인터뷰했습니다. 별도의 1차·2차 조사로 나눈 것이 아니라, 인터뷰 도중 얻은 내용을 바탕으로 질문의 초점을 수정했습니다.

| 진행 상태 | 인터뷰 수 | 과정 |
|---|---:|---|
| 인터뷰 완료 | 11명 | 초기에는 재고·발주·공동구매 전제를 폭넓게 탐색했고, 중간 분석 후 거래처·가격 정보 비대칭을 더 구체적으로 질문함 |
| 상세 로그 정리 예정 | 11건 | 음성 및 인터뷰 정리본을 받은 뒤 `I01`~`I11`로 익명화해 추가 |

## 개인정보 원칙

공개 저장소에는 매장명, 사장님 성명, 연락처, 정확한 주소, 음성 파일을 저장하지 않습니다. 실제 인터뷰 로그에는 `I01`부터 `I11`까지 연속 번호만 사용합니다.
