# 인터뷰 인덱스

총 11명의 자영업자를 연속적으로 인터뷰했습니다. 별도의 1차·2차 조사로 나눈 것이 아니라, 인터뷰 도중 얻은 내용을 바탕으로 질문의 초점을 수정했습니다.

| 진행 상태 | 인터뷰 수 | 과정 |
|---|---:|---|
| 질문 수정 전 | 7명 | `I01`~`I07`, 재고·발주·공동구매 전제를 폭넓게 탐색 |
| 질문 수정 후 | 4명 | `I08`~`I11`, 거래처 탐색·가격 판단·정보 교환을 구체적으로 질문 |
| 내용 코딩 완료 | 8건 | `I01`~`I06`, `I09`, `I10` |
| 내용 확인 대기 | 3건 | `I07`은 음성 수령 대기, `I08`과 `I11`은 음성은 있으나 전사·내용 검토 대기 |

## 개인정보 원칙

공개 저장소에는 매장명, 사장님 성명, 연락처와 정확한 주소를 저장하지 않습니다. 과제 증빙용 음성은 동의를 전제로 익명 ID 파일명으로 보관하며, 인터뷰 로그에도 `I01`부터 `I11`까지 연속 번호만 사용합니다.
