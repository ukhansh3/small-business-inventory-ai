# 현재 인터뷰 증거 행렬

## 분석 범위

인터뷰는 `I01`부터 `I11`까지 하나의 연속된 탐색입니다. `I01`~`I07`은 질문 수정 전, `I08`~`I11`은 질문 수정 후입니다. 질문하지 않은 내용은 반대 증거로 처리하지 않습니다.

| ID | 질문 시점 | 현재 자료 상태 | 실제 내용에서 확인한 핵심 | 정보 비대칭 가설에 미친 영향 |
|---|---|---|---|---|
| I01 | 수정 전 | 내용 확인 완료 | 신선도를 위해 소량 구매, 맛·신선도·근거리 배송과 관계를 중시 | 공동구매 약화, 정보 비대칭은 미확인 |
| I02 | 수정 전 | 내용 확인 완료 | 폐유 가격 차이를 주변 점주에게 듣고 업체 변경, 수리업체 탐색에 시간 사용 | 정보 비대칭의 강한 문제 신호 |
| I03 | 수정 전 | 내용 확인 완료 | 여러 구매처와 최저가 알림을 쓰지만 빠른 배송·운반 때문에 비싼 거래처도 유지 | 가격표만으로 해결하기 어렵다는 반대 근거 |
| I04 | 수정 전 | 내용 확인 완료 | 익숙한 대형 거래처를 편의성 때문에 유지, 가격 차이를 크게 느끼지 않음 | 모든 신규 점주가 문제를 겪는다는 가설 약화 |
| I05 | 수정 전 | 내용 확인 완료 | 업계 지인과 이전 경험으로 거래처를 찾고 품질에 따라 변경 | 인맥·경험의 영향 확인 |
| I06 | 수정 전 | 내용 확인 완료 | 매출에 맞춰 매일 또는 2~3일마다 직접 구매, 핵심 어려움은 손님 부족 | 정보 비대칭은 미확인 |
| I07 | 수정 전 | 음성 수령 대기 | 인터뷰 수행 사실과 순서만 확인 | 내용 확인 전 판정 제외 |
| I08 | 수정 후 | 음성 있음, 내용 확인 대기 | 인터뷰 수행 사실과 순서만 확인 | 내용 확인 전 판정 제외 |
| I09 | 수정 후 | 내용 확인 완료 | 과거 경험·저장한 연락처로 거래처를 하루 안에 결정, 경쟁 점주와 가격 공유는 꺼림 | 탐색 문제 부분 확인, 공개 공유 가설 약화 |
| I10 | 수정 후 | 내용 확인 완료 | 가족 소개로 구매 채널을 알았고 계속 가격 비교, 큰 부담은 구매·운반과 디지털 사용 | 초보 전용 가설 약화, 신체·디지털 부담이라는 다른 신호 |
| I11 | 수정 후 | 음성 있음, 내용 확인 대기 | 인터뷰 수행 사실과 순서만 확인 | 내용 확인 전 판정 제외 |

## 현재 판정

| 가설 | 판정 | 이유 |
|---|---|---|
| H1-a 문제 빈도 | 근거 부족 | 거래처 변경은 간헐적이었고 `월 1회 이상` 같은 공통 빈도는 확인되지 않음 |
| H1-b 탐색 비용 | 부분 확인 | 폐유·수리·새 식자재 거래처 사례는 있었으나 경험과 연락처로 빠르게 해결한 사례도 있음 |
| H1-c 정보 공유 | 수정 필요 | 지인 소개는 유효했지만 경쟁 점주끼리 공개 공유한다는 전제에는 반대 근거가 있음 |
| 초보 점주가 핵심 사용자 | 수정 필요 | 실제 표본에 장기 운영 점주가 있고, 업력보다 품목 경험과 디지털 활용 차이가 중요할 수 있음 |
| 중고거래·지도 필요 | 미확인 | 해당 기능을 요구하거나 실제로 사용한 구체적 사건을 확인하지 못함 |

## 해석 시 주의

- `I01`~`I06`은 정보 비대칭 전용 대본으로 진행하지 않았으므로 관련 발언이 없다는 이유만으로 가설을 기각하지 않습니다.
- `I07`, `I08`, `I11`은 내용 확인 전이므로 수치 집계에서 제외합니다.
- 음성 자동 전사에는 오인식이 있을 수 있어 애매한 숫자와 고유명사는 인용하지 않았습니다.
- 인터뷰 표본이 대학가 외식업에 집중돼 다른 지역과 업종으로 일반화할 수 없습니다.
