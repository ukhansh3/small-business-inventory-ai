# I01 인터뷰 로그

## 추적 메타데이터

- 인터뷰 일시: 공개 자료에서 미확인
- 질문 버전: G01(질문 수정 전)
- 원음: `data/interviews/audio/I01.m4a`
- 직접 인용: 원음 대조 전이므로 현재 공개 로그에 없음
- 수치 판정 사용: 구매·폐기 빈도만 제한적으로 사용, 거래처 탐색 비용 판정에는 사용하지 않음

- 질문 시점: 수정 전
- 자료 상태: 음성 및 전사 내용 확인 완료
- 업종: 외식업
- 업력: 현 매장 약 10개월, 이전 외식업 운영 경험 있음

## 확인된 과거 행동

- 밀가루·고기·채소는 직접 사고 일부 품목은 메신저로 주문했습니다.
- 신선도를 위해 소량을 자주 구매하고, 남기는 것보다 부족하게 준비하는 편을 택했습니다.
- 새 메뉴용 재료가 남아 폐기된 경험이 있었고 여름에는 월 1~2회 정도라고 설명했습니다.
- 거래처를 정할 때 맛, 신선도, 가까운 거리의 빠른 배송을 확인했고 이후에는 관계와 신뢰 때문에 유지했습니다.

## 사건 ID와 수치

- `I01-E01`: 신선도를 위해 소량을 자주 구매하고 일부 품목을 메신저로 주문함. 정확한 구매처 수·시간·금액은 미확인.
- `I01-E02`: 새 메뉴 재료가 남아 폐기됐고 여름에는 월 1~2회라고 설명함. 폐기 금액은 미확인.
- `I01-E03`: 맛·신선도·근거리 배송·관계를 기준으로 거래처를 유지함. 최근 신규 거래처 선택 시점은 미확인.

## 가설에 미친 영향

- 공동구매: 약화. 묶음 가격보다 신선도와 빠른 공급이 중요했습니다.
- 정보 비대칭: 확인하지 못함. 거래처 탐색 비용이나 적정가 판단 문제를 구체적으로 묻지 않았습니다.

## 해석 메모

가장 큰 운영 어려움은 거래처 정보보다 매출이었습니다. 수정 전 질문이므로 정보 비대칭 발언 부재를 반대 증거로 사용하지 않습니다.
