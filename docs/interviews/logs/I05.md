# I05 인터뷰 로그

- 질문 시점: 수정 전
- 자료 상태: 음성 및 전사 내용 확인 완료
- 업종: 외식업
- 업력: 약 2년 6개월

## 확인된 과거 행동

- 온라인과 앱으로 주문했고 신선육은 필요한 양만 거의 매일 주문했습니다.
- 방학에는 남은 재료를 직접 소비하거나 폐기한 경험이 있었습니다.
- 육류 거래처 3~4곳을 품질과 공급 목록에 따라 바꿔 사용했으며 가격은 두 번째 기준이라고 설명했습니다.
- 정육·육류업에 종사하는 지인과 본인의 과거 경험을 통해 거래처를 찾았습니다.
- 가장 큰 어려움은 거래처 정보보다 수요와 매출이었습니다.

## 가설에 미친 영향

- 인맥·경험의 영향: 확인. 공개 검색보다 업계 지인과 과거 경험이 거래처 선택을 도왔습니다.
- 가격 비교만의 해결책: 약화. 품질이 더 우선이었습니다.
- 공개 정보 공유: 확인하지 못함. 친분이 있는 업계 지인의 도움과 점주 커뮤니티 공유는 구분해야 합니다.

## 해석 메모

비공식 네트워크의 가치가 보이지만, 모르는 점주끼리 정보를 공개할 것이라는 근거는 아닙니다.
