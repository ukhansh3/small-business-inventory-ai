# 인터뷰 로그

이 디렉터리에는 익명화된 인터뷰별 확인 결과를 저장합니다.

파일명 형식:

```text
I01.md
I02.md
```

전체 인터뷰는 `I01`부터 `I12`까지 연속 번호를 사용합니다. 질문이 수정됐더라도 번호 체계를 나누지 않습니다.

과제 증빙용 음성 파일은 [`data/interviews/audio`](../../../data/interviews/audio)에 익명 ID로 보관합니다. 원본 전사본, 연락처, 점주 실명과 정확한 주소는 저장소 밖에 보관하고, 공개 로그에는 [기록 양식](../templates/interview-note.md)에 맞춘 익명화 결과만 추가합니다.
