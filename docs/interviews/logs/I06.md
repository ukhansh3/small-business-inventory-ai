# I06 인터뷰 로그

## 추적 메타데이터

- 인터뷰 일시: 공개 자료에서 미확인
- 질문 버전: G01(질문 수정 전)
- 원음: `data/interviews/audio/I06.m4a`
- 직접 인용: 원음 대조 전이므로 현재 공개 로그에 없음
- 업력: 전사상 범위가 불명확해 원음 확인 전 확정하지 않음

- 질문 시점: 수정 전
- 자료 상태: 음성 및 전사 내용 확인 완료
- 업종: 외식업
- 업력: 전사상 약 1년 6개월~2년 6개월로 불명확

## 확인된 과거 행동

- 식자재를 직접 구매했고 매출에 맞춰 매일 또는 2~3일마다 주문했습니다.
- 비교적 저렴한 원재료를 조리 방식으로 보완해 품질을 맞춘다고 설명했습니다.
- 수요가 일정하지 않아 재료가 남거나 부족한 일이 있었지만 최근 사건의 횟수와 금액은 확인하지 못했습니다.
- 가장 큰 어려움은 거래처 정보보다 손님 부족이었습니다.

## 사건 ID와 수치

- `I06-E01`: 매출에 맞춰 매일 또는 2~3일마다 직접 구매함.
- `I06-E02`: 재료가 남거나 부족한 경험은 있으나 최근 횟수·금액은 미확인.
- 거래처를 새로 찾은 사건·접촉 수·탐색 시간은 질문하지 않아 H1 판정에 사용하지 않음.

## 가설에 미친 영향

- 공동구매: 약화. 판매량에 맞춘 잦은 구매가 중심이었습니다.
- 정보 비대칭: 확인하지 못함. 거래처 탐색 사건과 비용을 묻지 않았습니다.

## 해석 메모

업력 표현이 전사 과정에서 일관되지 않아 범위로 기록했습니다. 원음 재확인 전 정확한 숫자로 사용하지 않습니다.
