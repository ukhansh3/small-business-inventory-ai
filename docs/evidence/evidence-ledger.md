## 갱신 규칙

- 새 근거를 추가할 때 로그 사건 ID를 먼저 만든다.
- 반대 근거를 삭제하지 않는다.
- 직접 인용은 원음 타임스탬프와 익명화 확인 후만 사용한다.
- 제품 기능·공공데이터·코드 구현을 인터뷰 문제의 지지 근거로 추가하지 않는다.
