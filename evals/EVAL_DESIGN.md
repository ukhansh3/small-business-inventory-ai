# 천하장사 텍스트 Evals 설계

`evalset.jsonl`은 v2의 기존 텍스트 32건과 같은 입력·기대값을 사용한다. 앱 폴더에서 `npm run evals`로 실행한다. 실시간 모델에는 승인된 API 환경이 필요하며 PR CI에서는 호출하지 않는다.

| 지표 | 합격선 | 연결 |
|---|---|---|
| 검색·단가 조건 완전 일치 | 90% 이상 | 앱 AC-5·AC-24 |
| 도구 형식 검증 통과 | 100% | 앱 AC-15 및 도구 JSON Schema |
| 범위 밖·무관 요청 분류 | 100% | 앱 AC-10·AC-11 |
| 없는 값 생성·허용 밖 활성 품목 ID | 각각 0건 | 앱 AC-6, 루트 AC13 |

모든 지표는 코드로 채점한다. 미응답·호출 오류는 성공 분모에서 빼지 않고 별도 집계한다. 수량·금액을 포함해 누락으로 기대한 필드를 채우면 생성 오류로 기록한다. 동점인 지표라도 모델·카탈로그 조건을 확인할 수 없는 비교는 단순 참고로 표시한다.

결과 JSON과 history.csv에는 실행 시각, 커밋, 모델, 프롬프트 버전, 데이터셋 해시, 골든 상태, 케이스별 기대·실제값·실패 유형을 기록한다. 실패는 최대 10건의 ID와 범주별 수로 요약한다. 사진 평가는 앱의 기존 11건 결과를 별도로 보존한다.

이 32건은 비교 기준선이다. 조건 충돌·인젝션·허위 업체 유도를 위한 확장 데이터와 SPEC의 AC13 반복 평가는 별도다.
