# 골든 케이스 사용법

`golden-cases.yaml`은 테스트 코드가 아니라 팀이 먼저 승인할 입력·기대 결과 정본입니다.

1. 팀이 케이스와 경계값을 검토합니다.
2. 승인 commit SHA를 SPEC에 기록합니다.
3. 서버 Vitest와 모바일 계약 테스트에서 각 ID를 참조합니다.
4. 필수 케이스는 skip·xfail 없이 통과해야 합니다.
5. 결과가 불편하다는 이유로 기대값을 사후 수정하지 않습니다. 계약이 바뀌면 ADR·SPEC·골든 케이스를 함께 변경합니다.

현재 `AC04` 배송 필드, `AC07` 비교 기능, `AC13` AI는 구현 gap 또는 P1이므로 대응 테스트가 아직 없을 수 있습니다. 이 상태를 통과로 기록하지 않습니다.
