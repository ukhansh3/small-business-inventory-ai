천하장사 UI 검토용 5탭 미리보기

가상 화면 · 기능 미연결　목업 기반 배치 초안

사용자가 승인한 흰 배경·검정 텍스트·주황 포인트, 지도 중심 홈, 초기 접힌 시트, AI 채팅 카드, 커뮤니티, 저장, UI 전용 내 정보를 한 파일에서 확인할 수 있어.

사용 방법: 휴대폰 하단 탭을 눌러 화면을 바꿔봐. 지도 핀을 누르면 하단 카드의 표시를 확인할 수 있어.

이 파일은 HTML 시각 배치 검토만 위한 것이며 실제 지도 타일, DB, LLM, 글 작성, 저장 API는 연결되어 있지 않아. 실제 작동 검증은 이후 Android/서버 통합 단계에서 수행해야 해.

구현 지침: docs/ui/design-system.md, docs/scenarios/screens-review.md, docs/scenarios/end-to-end-demo.md를 함께 확인할 것.
